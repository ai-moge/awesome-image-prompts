```
アップロードされた写真を、独立して成立するプレミアムな3:4縦型デザインポスターに変換してください。

1. 全体構成とレイアウト

キャンバス全体を、完全に同じ大きさの2つの水平セクションに分割してください。

- 上部50％：オリジナルの写真画像。
- 下部50％：写真の本質から導き出した抽象的なビジュアルアイデンティティ。

2つのセクションは、縦方向に正確な1:1の比率で分割してください。最終結果は、洗練されたアート出版物、実験的なデザインポスター、ハイエンドなビジュアルアイデンティティシステムを思わせるものにしてください。

2. 上部セクション — アートフォトグラフィー

元写真の被写体、構図、構造的ディテール、写実的な質感、自然光、影、本来の色彩の雰囲気を維持してください。

画像をエディトリアルなファインアート写真の美学へ高めるため、繊細で洗練されたカラーグレーディングのみを施してください。

- 元の被写体のアイデンティティ、比率、ポーズ、身体的特徴を維持する。
- 被写体を引き伸ばしたり、歪めたり、再構築したり、変更したりしない。
- 3:4の縦型構図に対応する必要がある場合は、背景を自然に拡張する。
- 元の写真らしいリアリズムを維持する。
- 過度なレタッチ、人工的な効果、過剰に様式化されたカラーグレーディングを避ける。

結果は、独立系アート＆デザイン誌に掲載される上質なエディトリアル写真のようにしてください。

3. 下部セクション — 抽象的ビジュアルアイデンティティ

写真の本質的なビジュアルDNAを抽出し、独立した抽象的なグラフィックシンボルへ変換してください。

被写体の中で最も認識しやすい特徴を特定してください。

- シルエットと全体の輪郭。
- 構造的な幾何学性と特徴的な形状。
- ポーズ、動き、空間的な関係。
- 中心となる物語性と感情的な性格。

被写体全体を再現したり、写実的なイラストを制作したりしないでください。代わりに、その決定的な特徴を、ミニマルで認識可能な抽象的ビジュアルマークへ還元してください。

以下を使用してください。

- 幾何学的な脱構築。
- モジュール形状と構造ブロック。
- 精密な線描と建築的幾何学。
- ネガティブスペース。
- 象徴的な形状と視覚的単純化。
- 円形軌道、グリッド、抽象的なノード。

最終的なシンボルは、ハイエンドなクリエイティブスタジオ、実験的デザインレーベル、建築事務所、または現代美術機関の中心的なアイデンティティマークのように見せてください。

4. ビジュアルデザイン言語

以下を洗練された形で組み合わせてください。

- ポストデジタル・グラフィックデザイン。
- 脱構築されたスイスデザイン。
- 生成的シンボルシステム。
- ダイアグラム的抽象表現。
- 実験的なエディトリアルタイポグラフィ。
- 現代的なビジュアルアイデンティティデザイン。

以下の間に視覚的な緊張感を生み出してください。

- 秩序と不完全さ。
- 精密さと手作業による不均一さ。
- デジタルシステムとアナログ美学。
- 合理的な幾何学と感情表現。

幾何学的モジュール、繊細な線、円弧、控えめなグリッド、マイクロシンボル、番号体系、抽象的な構造接続を使用してください。

構図は極めて抑制されたものにしてください。抽象シンボルは唯一の主要な視覚的焦点として、中央またはわずかに中央から外した位置に配置し、周囲に十分なネガティブスペースを確保してください。

視覚的な混雑、過剰な装飾、競合する複数のアイコン、インフォグラフィック風のレイアウトは避けてください。

5. タイポグラフィと微細なディテール

タイポグラフィはビジュアルシステムの控えめな要素としてのみ機能させ、メイン見出しにはしないでください。

必要に応じて以下を取り入れてください。

- 小さなシリアル番号。
- 最小限の英数字コード。
- 短い実験的注釈。
- 小さな索引ラベル。
- 繊細なタイポグラフィマーカー。

アーカイブ的、技術的、実験出版物的な美学を備えた、洗練されたミニマルな書体を使用してください。

すべての文字要素は意図的であり、抽象シンボルと構造的につながっているように見せてください。

6. カラーシステム

元写真から、支配的で最も特徴的な色を直接抽出してください。

それらを一貫性のあるビジュアルアイデンティティのカラーパレットとして再解釈してください。

以下を使用してください。

- 主背景にはウォームホワイト、オフホワイト、または柔らかなグレー。
- 元画像に根拠がある場合は、ティール、シアン、ブルー、マゼンタ、オレンジなどの抑制されたアクセントカラー。
- 機能的な視覚コードとして、意図的に配置した小さな色のアクセント。

色は装飾ではなく、構造とアイデンティティを伝えるために使用してください。

混乱した配色、安っぽいネオン効果、過飽和のパレット、一般的な商業グラデーションは避けてください。

7. 印刷テクスチャと素材処理

デジタル構成に、印刷された実験的アート出版物の触覚的な質感を与えるため、繊細な物理的不完全さを加えてください。

以下を取り入れてください。

- Xeroxコピーの質感。
- リソグラフの粒子。
- わずかな印刷位置のずれ。
- 細かなスキャナーノイズ。
- 繊細な紙の粒子。
- わずかに不完全なエッジ。
- 最小限のアナログ印刷アーティファクト。

これらの質感は極めて繊細かつ制御されたものにしてください。明瞭さ、精度、視覚的階層を損なわずに、素材感を高める必要があります。

8. 最終アートディレクション

最終ポスターは、元写真から直接抽出された、洗練された独立性のあるビジュアルアイデンティティの感覚を伝えてください。

上半分は、本物らしい写真によって元の被写体を表現します。

下半分は、独立して認識できる抽象的なグラフィックアイデンティティによって、その視覚的本質を表現します。

2つのセクションは異なるビジュアル言語を保ちながら、コンセプト上はつながっているようにしてください。

クリエイティブリファレンス：現代美術機関、実験的出版、建築的アイデンティティシステム、スイス・グラフィックデザイン、独立系クリエイティブスタジオ、ハイエンドなカルチャーブランディング。

最終的な美学：ミニマル、知的、コンセプチュアル、建築的、エディトリアル、触覚的、視覚的に独自。

厳格な要件：

- 3:4の縦型アスペクト比。
- 写真50％、抽象表現50％の正確な分割。
- 被写体を歪めず、元写真を維持する。
- 下半分には1つの主要な抽象シンボルのみを配置する。
- 十分なネガティブスペース。
- 洗練された抑制的なカラーパレット。
```
