#### 📚 説明

アップロードした人物写真を、統一感のある4枚のファッションエディトリアルポスターに変換し、それぞれ異なるタイポグラフィのレイアウトで構成する。

<summary>プロンプト全文を表示</summary>

```
アップロードした写真から、すべて同じビジュアルシステムに属する4つの独立した人物ポスターのバリエーションを作成してください。

人物写真：[アップロードした人物写真を使用]
メインカラー：[ミントグリーン / 赤 / 青 / 黄 / カスタム]
タイポグラフィのテーマ：[SIGNAL / MOTION / ECHO / MINT、またはカスタムワード]
アスペクト比：9:16

4枚すべてのポスターで、同じ人物、顔の同一性、髪型、衣装、写真的リアリズム、カラーパレット、書体ファミリー、エディトリアルなアートディレクションを維持してください。

4枚のポスターは一つのまとまりのあるファッションエディトリアルシリーズのように感じられなければなりませんが、それぞれ明確に異なるレイアウトコンセプトを使う必要があります：

1. 垂直タイポ・レイヤリング
   特大のコンデンス書体を強い縦の背骨として使います。文字を人物の前後に走らせ、明確な奥行きと重なりの相互作用を生み出します。

2. スライスされた人物
   人物をいくつかのきれいな水平セクションに分割し、各スライスをわずかにずらします。顔が認識でき美しい状態を保ちます。RGBグリッチ、ノイズ、デジタルな歪みは避けてください。

3. エコー・ポートレート
   対照的なスケールや向きを使って同じ被写体を2回見せます。たとえば通常の人物像と、拡大・反転した人物像です。繰り返しのタイポグラフィやアウトライン書体で視覚的な「エコー」を作ります。

4. 特大書体の中の人物
   巨大で太いタイポグラフィをメインの構図として使います。顔、目、唇、髪、肩の一部を文字の間や隙間から覗かせ、人物がタイポグラフィに溶け込むようにします。

特大のコンデンス・サンセリフ書体、力強い人物写真、クリーンな幾何学的構造、ゆとりある余白、細い罫線、意味のある小さなエディトリアルテキスト、控えめなグラフィックブロックを用いた、モダンなファッションエディトリアルの美学を使ってください。

情報の階層を明確に保ちます：大きなタイポグラフィが第一、人物が第二、小さなエディトリアルテキストが第三です。

ランダムなプレースホルダーテキストではなく、ビジュアルコンセプトに関連した意味のあるサポートコピーを使ってください。

肌は自然な質感でリアルに保ち、リアルな髪の毛、自然な布のしわ、写真的なライティングを施してください。プラスチックのような肌、CGI風の見た目、過度なレタッチ、ランダムな記号、無意味なテキスト、重いUIグラフィック、きらめき、番号付け、NO.、VOL.、装飾的な雑然さは避けてください。

4枚すべてを別々の独立した9:16ポスターとして生成し、1枚のコラージュにまとめないでください。
```

### No. 4: 紙繊維で描く東洋文化ポスター

#### 📚 説明

紙繊維の大きな色面、たっぷりの余白、極小の伝統工芸の淡彩シーンを組み合わせた現代東洋文化ポスターを生成する。

#### 🌟 プロンプト

「紙繊維＋大色面＋意図的な余白＋微型文化シーン」を核とした現代東洋文化イベントのポスターをデザインする。

背景には温かみのある柔らかな暖アイボリーホワイトの手漉き紙を使い、約45%〜60%の大きな余白を残す。【核となる大色面】で第一視覚を確立し、【構造の方法】に従って明確で方法論的な大きな形の関係を作る。テーマは繊維の放射、紙面の切り抜き、亀裂の接続、正負形の転換、拓本の痕跡などで表現してよいが、普通の写実的な物体にはしないこと。

大色面には明確な天然紙繊維、パルプ粒、水彩や鉱物顔料の沈着、自然な毛羽立ちの縁、マットな質感を持たせる。全体に【主色調】を用い、低彩度だが完全で濃度のある色にする。遠くではまず大きな形と色の関係が見え、近づいて初めて素材の細部に気づく。

大色面の近くに、ごく小さなスケールの【微型文化シーン】を加え、人物が【人物の動作】を実際に行っている。人物・道具・【文化器物】は全体で約3%〜5%だけを占め、ポーズ撮りや商品陳列にはしない。

人物は一律に二次元の紙本淡彩イラスト技法を用いる：簡潔な顔立ち、軽い立体感、完全な平面色面、少量の連続した衣紋線で、紙と色面と同じ視覚世界に属する。写真的なリアル感、3Dミニチュア模型、CGIの光影、強い投影、リアルな被写界深度は避ける。

微型シーンと巨大なメインビジュアルの間に、繊維、紙屑、亀裂、鎹（かすがい）、墨跡、道具の軌跡、あるいは素材そのものといった、実際のスケールの接続を一つ作り、「小さな手仕事の動作」が自然に「大色面の構造」へと延びるようにする。

全体の読み順は：

余白と大色面 → 構造の関係 → 紙繊維の質感 → 微型文化シーン → 工芸の動作 → タイトルとイベント情報。

最終的には、遠くで目を引き、近くで紙の質感・細部・文化の物語がある東洋のエディトリアルポスターに仕上げる。
