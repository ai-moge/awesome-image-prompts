フェーズ10：品質管理

彫刻は物理的に妥当な形状、人体と比率は正確にする。物理的根拠のない浮遊物、歪んだ建築、人工的なCGIやゲーム風表現、誤ったロゴ、スペルミス、不要な装飾、混雑した構図、一般的なストック広告感を排除する。
