1. 運動員與姿勢

2. 羽毛球雕塑

讓超大羽毛球成為構圖中占主導地位的建築式元素。其圓潤的軟木球頭應具有精緻、略帶紋理的表面，大型白色羽毛結構則以戲劇化且富有雕塑感的排列向外延伸。加入真實的羽毛細節、細膩陰影與精心設計的比例。運動員應自然地融入雕塑之中，彷彿正斜躺在一件非凡的當代家具上。

將巨大的「BADMINTON」字樣醒目地置於背景上方，使用粗體、超大尺寸、窄長的全大寫字體。採用溫暖的象牙色或奶油白色，營造強烈的編輯視覺存在感。字體應乾淨、銳利且高度清晰，在不搶奪運動員焦點的前提下建立強烈的視覺識別。於文字附近加入一個小巧、低調的羽毛球圖形，作為互補性的設計細節。

4. 環境與背景

5. 燈光與視覺美學

使用電影感棚拍燈光，搭配精準控制的高光、柔和的方向性陰影與細膩反射。照亮白色羽毛球雕塑，以強調其紋理與立體結構，同時保留優美膚色與真實布料細節。加入細微的空氣感層次與精緻調色，呈現精修完善的奢華廣告外觀。

6. 最終藝術指導

輸出：正方形1:1長寬比、全身運動員、超大型雕塑羽毛球、占主導地位的BADMINTON字體排版、平衡的編輯式構圖、超精細紋理、電影感燈光與高級廣告質感。不要浮水印、不要不必要物件、不要扭曲的人體結構或具有人工感的細節。

以超大尺度實驗字體、非對稱構圖，以及文字、核心視覺與展覽資訊之間的空間融合，創作具有東方文化氣質的藝術海報。

以藝術化構圖為最高優先級，打破傳統海報的區塊化佈局。先建立具有視覺衝擊力的整體構圖，再將字體、主體、圖形和展覽資訊自然融入其中，而不是按照固定模板填充內容。

二、核心視覺與字體設計

根據主題選擇具有代表性的藝術物件，採用真實攝影、藝術繪畫或具有物理可信度的立體表現，突出主體的材質、形態、光影與空間層次。

中文標題採用超大尺度的實驗性字體，可使用現代高對比宋體、幾何字形、狂草書法或空間立體字形。透過極端尺度對比、局部裁切、錯位疊壓、負空間與透視關係，讓文字成為構圖本身。

讓主體與字體產生具有創意的結構關係，例如建築鏤空構成漢字、舞者動作延續書法筆勢、織錦穿越文字結構、飛鳥羽翼與字形交錯。避免簡單的圖文疊加，強調真實的空間互動與視覺融合。

允許局部文字高度密集，其他區域保持自然留白。網格隱藏於構圖秩序之中，而不是直接表現為規則的資訊框。

四、資訊密度與自由佈局

保留展覽日期、策展機構、主題說明、中英文短文及必要的專業註釋，但不設置固定的資訊區域。讓文字沿主體輪廓、字體筆畫、運動軌跡和自然負空間錯落分佈，使資訊本身參與藝術構圖。

資訊豐富但不區塊化，複雜但不雜亂。避免機械的頂部標題、中部主體、底部資訊欄結構，以及標準化頁首頁尾、矩形資訊框、固定分欄和過多裝飾性細線。

讓海報不僅是傳達展覽資訊的媒介，更是一件本身就值得被展覽的實驗性平面設計作品。

核心哲學：「我們所看見的一切，都是由我們看不見的事物構成。」

作品必須揭示賦予照片主體意義的不可見情感、哲學、文化、歷史或存在性成分。最終構圖應如同對主體隱藏身分的一次視覺解剖。

1. 主體分析——發現象徵成分
先仔細分析上傳的照片，辨識主要主體、代表性特徵、視覺關係、環境、姿態、狀態與情緒氛圍。接著提問：「如果這個主體不是由物質構成，它會由哪些不可見的事物構成？」找出3至5個與照片主體具體相關且有意義的象徵成分。它們可以涉及記憶、韌性、渴望、歸屬、矛盾、轉變、時間、希望、脆弱、連結，或影像真正暗示的其他概念。不要自動採用這些例子，必須從實際照片中獨立推導。避免明顯、膚淺、籠統或可任意替換的詮釋；所選成分必須揭示這個特定主體值得深思的一面。

創作精緻的抽象構圖，讓原本的照片主體看似由不可見的象徵成分構成。將每個成分轉化為獨特的視覺形式。例如，韌性可成為即使出現裂痕仍保持連結的幾何結構；記憶可成為保留過往形狀痕跡的半透明重疊形式；自由可成為延伸至僵硬幾何邊界之外的開放曲線。這些只是概念示例，並非強制元素。請根據實際照片及所選成分創造原創幾何詮釋。最終作品應像是主體被拆解為不可見的成分，再經過仔細重組；形成的符號仍須與原主體的代表性輪廓、結構或視覺性格保持連結。
