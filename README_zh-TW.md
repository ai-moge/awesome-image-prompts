### No. 2: 照片變身手作餅乾組

![分類: 創意視覺](https://img.shields.io/badge/%E5%88%86%E9%A1%9E-%E5%89%B5%E6%84%8F%E8%A6%96%E8%A6%BA-lightgrey)

#### 📚 描述

將 3:4 畫面上下對半分割，上半是原照片，下半是忠實還原主體的樸實手作迷你餅乾組與量身設計的包裝。

#### 🌟 提示詞

仔細逐一觀察每張上傳的照片，並把每一張變成一張獨立的設計海報。不要把多張照片拼成拼貼。永遠每張照片輸出一件作品。 整體格式為 3:4 直式構圖。將畫布水平方向精確對半分割，上 50%、下 50%。 上 50% = …

<summary>展開完整提示詞</summary>

```
仔細逐一觀察每張上傳的照片，並把每一張變成一張獨立的設計海報。不要把多張照片拼成拼貼。永遠每張照片輸出一件作品。

整體格式為 3:4 直式構圖。將畫布水平方向精確對半分割，上 50%、下 50%。

上 50% = 原始照片
下 50% = 一組受照片啟發的小型手作餅乾

【上半｜原始照片｜最重要】

原封不動地使用原始照片。

不要把人物、貓、狗、動物、建築、花、食物、物件、風景或任何其他主體換成別的東西。準確保留臉部、表情、眼睛、耳朵、髮型、毛色、花紋、體型、姿態、姿勢、服裝、隨身物、朝向、色彩、光線與整體氛圍。

僅在必要時自然延伸背景。不要扭曲或更動主體本身。

【下半｜小型手作餅乾組】

仔細觀察原始照片，選出一個最能代表該影像的主體。

做出一個重現該主體的「主體餅乾」，再加上 2–4 個自然受照片主體、地點、季節、事件或氛圍啟發的「相關迷你餅乾」，整組約 3–5 個小餅乾。

例如若主體是貓，就做出貓本身，再加上魚、零食、毛線球、腳印或玩具等，挑選最適合那隻特定的貓與那張照片的元素。

不要每次都用同樣的組合。為每張照片個別設計內容。

【最重要｜不要把主體一般化】

不要把主體餅乾換成「通用的貓」「通用的狗」「通用的人」或其他一般化版本。

餅乾必須代表原始照片中確切的那個個體、動物或物件。

特別留意:

* 臉型
* 表情
* 眼型
* 耳朵形狀與角度
* 髮型
* 毛色與花紋
* 體型
* 朝向
* 姿態與姿勢
* 具辨識度的隨身物或配件

盡可能讓這些細節與原始照片相符。

對貓而言，僅能被辨認為「一隻貓」是不夠的。與上方照片相比時，最高優先是讓人感覺:

「這就是這隻貓！」

若主體為側臉，就保持側臉；若看起來想睡，就保留睏倦表情；若是坐著，就重現同樣的坐姿。不要擅自轉成正面或改成別的姿勢。

【如何製作餅乾】

不要把照片印在餅乾上。

而是把餅乾切成主體與各主題的實際形狀。

不要只是在普通圓餅乾上畫褐色線條。

用手作餅乾實際可行的方式重現特徵，例如外輪廓、淺浮雕細節，以及麵團顏色的自然變化。

【樸實手作感】

所有餅乾都應相當小，為迷你尺寸。

不要做得像量產品那樣完美光滑。保留以下細節:

* 略不平整的輪廓
* 細微的變形
* 不對稱的形狀
* 不均勻的厚度
* 細小的裂痕或氣泡
* 圓潤的邊緣
* 烘烤色澤的自然變化

它們不該看起來像失敗的餅乾，而應帶有一片片手工裁切與烘烤的迷人不規則感。

然而，手作質感不得把主體的臉部或辨識特徵扭曲到看起來像別的主體。

【包裝｜每張照片都要更換】

把 3–5 個迷你餅乾一起裝進一個小包裝。

不要為包裝使用固定的顏色、圖案、材質、繩子或小標籤。依原始照片自動設計。

從主體的毛、衣物、花、風景、季節、天空、光線或點綴色等元素中萃取 2–3 種顏色，轉化為柔和、略為降低飽和度的色盤。

若使用圖案，做成受照片啟發的小主題、低調的手繪風圖案。不要印上照片本身。

選擇適合該照片的包裝材質，例如:

* 透明袋
* 半透明的玻璃紙
* 蠟紙
* 自然的米白薄棉紙
* 小紙袋

保留手工包裝的溫度，帶有自然的皺褶、略不均勻的摺線與些微錯位。

【最重要｜不要裝飾背景】

下半的背景只能由與照片調和的極淡素色紙構成，例如:

* 奶油白
* 象牙白
* 自然米白
* 淺米色
* 淡灰白

不要在背景加入任何花、植物、盤子、道具、緞帶、紙屑、圖案、插畫或其他裝飾。

那裡除了包裝好的餅乾組之外不應放置任何東西。留下大量留白。

【最重要｜讓整組保持小巧緊湊】

不只是餅乾，含包裝在內的整組都應顯得相當小。

作為參考，整個包裝只應佔下半寬度約 25–30%。不要放大到填滿下半區域。

構圖應像是一個小包裹隨意放在一片寬廣素色留白的中央附近。

這個小包裹應顯得小巧、柔軟、略為飽滿，幾乎像是被隨手放在那裡。

它可以略微傾斜，裡面的迷你餅乾可以自然重疊。但主體餅乾的臉、形狀與辨識特徵仍應清晰可辨。

使用柔和自然光，只帶極淡的接觸陰影。不要讓包裹懸浮在半空。它應顯得自然放在真實的紙上。

【最終影像】

上 50% = 原封不動的原始照片
下 50% = 與照片高度相似的主體餅乾 + 受照片啟發的相關迷你餅乾 + 專為該照片設計的客製包裝

主體應具有與原始照片相同的臉部、表情、朝向、姿態與辨識特徵。

餅乾應小巧、略不平整、樸實且手作。

包裝應依每張照片改變顏色、圖案與材質。

背景必須保持完全簡單素淨。

整組應相當小，緊湊地置於大量留白之中。

將上方照片與下方餅乾相比時，完成的作品應讓觀者感覺:

「這張照片被直接變成了一組小小的手作餅乾！」
```
