### No. 4: 曲線構圖編輯風海報

![分類: 行銷物料](https://img.shields.io/badge/%E5%88%86%E9%A1%9E-%E8%A1%8C%E9%8A%B7%E7%89%A9%E6%96%99-lightgrey)

#### 📚 描述

以一條主曲線串聯主體、字體、圖片與留白，打造具後現代編輯設計感的強設計海報。

#### 🌟 提示詞

【主題】：\_\_\_\_ 【中文標題】：\_\_\_\_ 【英文標題】：\_\_\_\_ 【主視覺】：\_\_\_\_ 【曲線構圖方式】：曲線大字 / 曲面翻折 / 螺旋拼貼 / 曲線串聯 / 其他 【輔助素材】：\_\_\_\_ 【主色調】：\_\_\_\_ …

```
【主題】：____

【曲線構圖方式】：曲線大字 / 曲面翻折 / 螺旋拼貼 / 曲線串聯 / 其他

生成一張具有強設計感的曲線構圖海報，整體採用 Contemporary Editorial Poster × Postmodern Graphic Design × Cultural Exhibition Poster 的視覺語言。

先確定一條最重要的主曲線，再圍繞它組織主體、Typography、圖片、資訊和留白。曲線不是裝飾，而是整張海報的視覺骨架與閱讀路徑。

根據內容選擇一種主要曲線方式：

曲線大字：讓大型 Typography 本身發生拉伸、彎折、裁切和出框，字形直接成為曲線主視覺。

曲面翻折：讓紙張、織物、建築面或其他可彎曲實體形成巨大曲面，並把文字、圖片和資訊直接放在曲面上，隨透視自然彎曲。

螺旋拼貼：用一條開放式螺旋路徑串聯照片、票據、文字、人物和小型視覺節點，從外圍逐漸引導到核心。

曲線串聯：用一條連續 S 型或弧形主線穿過多個不同尺度的視覺節點，讓原本分散的圖片、人物和文字形成完整敘事。

整張海報只保留一個最強曲線方向，其他線條和元素只能跟隨或平衡主曲線，不製造新的視覺競爭。

主標題必須參與構圖，可順著曲線錯位、跨區、裁切、局部遮擋或改變尺度，不要只是整齊放在頂部。

畫面允許攝影、插畫、手寫、色塊、紙張、票據等 2–3 種視覺語言發生碰撞，但所有素材必須圍繞同一條曲線路徑組織，避免隨機貼紙式拼貼。

控制明顯的視覺層級：第一眼看到主曲線和主視覺；第二眼看到大標題；第三眼沿曲線路徑閱讀圖片和資訊；最後才看到日期、地點和極小輔助文字。

保留大面積有效留白，允許不對稱、裁切、尺度失衡、局部出框和輕微套色偏移，讓版式具有鬆動但有秩序的後現代編輯設計感。

色彩控制在 3–5 種，以一個大面積主色、一個強對比色和少量點綴色建立識別度。

整體要求：曲線明確、視覺抓眼、資訊豐富但不雜亂、有人工排版感、有設計學院和藝術出版物氣質。
```
