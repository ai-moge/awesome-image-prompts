創作一張「攝影質感 × 手繪線稿」虛實結合的創意海報。

畫面的核心是一件高度寫實的【核心寫實物體】，保留真實攝影級材質、紋理、光影、體積和細節；同時加入一位明顯採用鉛筆線稿、彩色鉛筆、蠟筆或輕水彩表現的【手繪人物】，形成清楚但自然的虛實反差。

不要只是把真人插畫和真實物體簡單拼在一起，而是讓【核心寫實物體】真正承擔【功能錯位】的用途，並與人物產生明確的物理互動。例如人物真的坐進去、握住、使用、依靠或躺在其中，讓觀眾第一眼就能理解這個略微超現實、但邏輯成立的視覺關係。

構圖採用「大主體 + 小人物 + 大留白 + 少量生活細節」。核心寫實物體要足夠大，縮圖狀態下也能立即辨識；人物相對較小，透過尺度反差加強視覺驚喜。

任務：建立一張3:4照片與日系插畫上下分割海報

1. 上半部 — 原始照片

- 完全按照原貌保留原始照片。
- 不得重繪、重新上色、修飾照片或在照片上添加任何文字。
- 按比例縮放，不得拉伸或扭曲影像。
- 如有必要，先裁切周邊背景區域，同時保留主要主體與重要的視覺細節。
- 如果無法在不損害關鍵內容的情況下配合長寬比，請使用淺灰奶油色背景延伸邊緣。絕不可虛構或重建原始照片中缺失的部分。

物件：

- 保留原始輪廓、必要的結構細節與比例。

- 將陰影合併為少量具有硬邊緣的色彩形狀。
- 避免逐根髮絲、密集排線、照片寫實質感與過度裝飾性細節。
- 保留主體必要的自然色彩，以及具有辨識作用的獨特配色圖案。

下方區域背景：淺灰奶油色「#ECEDE5」。

主要強調色：暖紅色「#E9444B」。

次要強調色：柔和藍灰色「#5296BD」。

以紅色作為主導強調色，藍色則少量使用。確保強調色能襯托主體，同時不影響其辨識度。

 所有側邊。
