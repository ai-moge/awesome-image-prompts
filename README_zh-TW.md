為咖啡館與烘焙店打造 9:16 直式海報，將寫實美食攝影與雜誌感表現性字體結合，並圍繞食物本身來構建版面。

字體排版應是構圖的主要部分。為主[主標題]使用一款富有表現力的展示字體，為次要資訊使用一款克制的輔助字體。允許在大小、方向、裁切與位置上變化，讓文字與食物融為一體，而不僅僅置於上方或下方。

### No. 2: 垂直切片文字編輯海報

![分類: 創意視覺](https://img.shields.io/badge/%E5%88%86%E9%A1%9E-%E5%89%B5%E6%84%8F%E8%A6%96%E8%A6%BA-lightgrey)

#### 📚 描述

製作高階直式編輯海報，中央放置大字，將一張連續照片嵌入文字並將筆畫向下延伸切片。

#### 🌟 提示詞

【MAIN WORD】：{4–8個字母的大寫關鍵字} 【PROJECT】：{展覽 / 節慶 / 文化活動 / 編輯} 【SUBJECT】：{一個完整的攝影場景} 【BACKGROUND】：{顏色} …

<details>
<summary>展開完整提示詞</summary>

```
【MAIN WORD】：{4–8個字母的大寫關鍵字}
【PROJECT】：{展覽 / 節慶 / 文化活動 / 編輯}
【SUBJECT】：{一個完整的攝影場景}
【BACKGROUND】：{顏色}
【PALETTE】：{主要色彩}
【TYPE STYLE】：{粗體無襯線 grotesk / 幾何無襯線 / 板襯線}
【TOP LEFT】：{日期 / 時間 / 場地}
【TOP RIGHT】：{3個簡短的概念詞}
【BOTTOM LEFT】：{補充資訊}
【BOTTOM RIGHT】：{機構 / 活動名稱}
【FORMAT】：9:16 直式

使用垂直切片文字排版製作一張高階編輯海報。

將【MAIN WORD】大大地放在中央，佔據約75–85%的寬度。保持字體粗厚、清楚可讀且視覺上具支配性。

在整個字裡嵌入一張單一連續的【SUBJECT】照片。每個字母都必須顯示同一張圖像的不同部分，光束、海岸線、建築、圓形、道路或物件等主要視覺線條要自然地跨字延續。

保持字形上方約40–45%完整。將選定的下方筆畫向下延伸成5–7個垂直區段，長度有短、中、長的變化。延伸部分必須從原始字母自然生長，絕不能看起來像隨機矩形或條碼條。

讓同一張照片延續穿過所有延伸區段。將最強的視覺焦點放在中央字母周圍，並用一個清晰連續的元素連接整個構圖。

在文字後方加上細緻柔和的陰影，略微向右下偏移，營造克制的漂浮紙張效果。

使用乾淨的【BACKGROUND】搭配充足的留白，並將大部分視覺複雜度保留在字體之內。將【PALETTE】套用於嵌入的照片，必要時加入一個小的強調色。

將補充資訊環繞構圖排列：

左上：【TOP LEFT】
右上：【TOP RIGHT】
左下：【BOTTOM LEFT】
右下：【BOTTOM RIGHT】

所有次要資訊使用小巧、精確的現代字體。最終成品應該像一張完成的展覽、節慶或文化編輯海報，而不是模板示範。

```
為麥當勞打造一張頂級創意代理商風格的品牌識別展示海報。將品牌無可辨認的視覺識別轉化為一套完整、精緻的品牌系統，讓它顯得鮮活、易辨識、充滿活力、俏皮且具全球標誌性。

[開心 / 魔幻 / 有趣 / 冒險 / 奇異 / 略帶恐怖 / 寧靜]

把孩子的夢境變成一個內容豐富的插畫夢境世界。

以夢境描述作為故事的基礎，但不要只是描繪一個字面上的場景。將它擴展成一個主要事件，加上數個彼此相連的小故事，彷彿同一個夢的不同片段一起在同一頁上展開。

把熟悉的記憶與日常物品轉化為富有想像力的夢境元素：臥室可以變成風景，被子可以化為河流，書本可以變成山脈，玩具可以活過來，房子可以飛起來，動物可以在天空旅行，平凡的物品可以悄悄變成某種魔幻的東西。

如果夢境是快樂或美好的，保留它的溫暖與奇妙感，讓它像一段值得珍藏的回憶。

如果夢境奇異或略帶恐怖，保留重要的故事元素，但透過溫和、繽紛、適合孩子的視覺語言重新詮釋——神秘而非嚇人，富想像力而非陰暗。

創作一個層次分明的構圖，包含數個大型流動的形狀、中等大小的故事場景，以及散佈在整幅畫面各處、隱藏的許多小發現。每個區域都應包含一個小故事，同時整幅畫面仍感覺像一個連續的夢。

讓所有色彩保持清新明淨，過渡平滑自然。只使用淡淡的水彩質感。
