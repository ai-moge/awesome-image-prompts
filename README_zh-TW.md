直式 4:5 廣告構圖。使用戲劇性的低角度建築透視，強化巨型尺度。雕塑橫跨畫面中上部，人物置於下方三分之一並稍微偏離中心。左上方刻意保留標題負空間，底部保留乾淨且高對比的官方 Spotify 標誌區域。

階段 6：字體／平面設計

LISTEN
BEYOND.

輔助文字保持極簡。整體字體需如高端國際廣告企劃，而非通用宣傳模板。

階段 7：品牌規範

尊重 Spotify 的正統視覺識別。使用作為獨立參考素材提供的官方標誌，精確保留圖示幾何、文字標誌、比例與原始配色。不得重繪、扭曲、拉伸、旋轉或重新詮釋。綠色標誌僅能用於合適的黑色或白色背景；其他背景應使用適當的官方單色版本。保留充足安全距離。不得虛構 Spotify 子品牌、產品功能、UI 元素或非官方標誌。

階段 8：社群媒體最佳化

階段 9：技術規格

直式 4:5；最低 4K，建議 8K；寫實商業攝影；ARRI Alexa 65 美學；35mm 鏡頭；電影感自然建築照明；高端廣告海報；精緻編輯調色、真實材質、細微底片顆粒與細膩色調對比。

階段 10：品質控管

確保雕塑幾何符合物理可信度；人體解剖與比例正確；不存在缺乏物理理由的漂浮物、扭曲建築、人工 CGI 或電玩感、錯誤 Spotify 標誌、拼字錯誤、不必要裝飾、擁擠構圖或通俗圖庫廣告感。

最終創意標準
