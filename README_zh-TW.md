Milk Cloud Orbit 食物光影邏輯：
這至關重要。純化最具說服力的產品區域：表面曲線上的奶油濃郁高光、糖晶閃光、酥脆金黃邊緣帶，以及精緻的烘焙質感陰影。每塊餅乾必須感覺更亮麗、更具觸感、更奢華編輯感，卻不顯油膩或人工。

餅乾必須始終是絕對的主角。文字排版、包裝、線條、圖示與趣味構圖裝置必須襯托產品，絕不壓過它們。每個格子都應感覺像一座高級餅乾聖殿。

背景色系統：
橫跨 9 個格子使用極簡的不同飽和色塊，取自精緻的烘焙調色盤：
溫暖奶油橙、淡奶油、烤金、柔和焦糖、沉靜餅乾米色、香草象牙白，以及偶爾更深的蜜棕點綴。

文字與標籤邏輯：
僅在需要處使用優雅的英文標題與小型產品標籤。你可以包含克制的標題，例如：

「PRETZEL ICON」
「ASSORTED SELECTION」
「RAISIN BUTTER CRISP」
「GOLDEN SWIRL」
讓文字保持極簡、優美間距，並次於產品。避免過度說明。

圖形點綴邏輯：
只加入低調的高級圖形裝置：細線、微小標註標籤、迷你產品識別，或非常克制的烘焙圖解點綴。這些應讓看板顯得聰明有設計感，但仍保持極簡。

包裝邏輯：
凡出現包裝之處，都必須感覺優雅高級，帶有寫實的 Kjeldsens 風格禮品餅乾品牌識別。包裝應襯托產品家族，絕不主導看板。

燈光：

表面與質感：

氛圍：
