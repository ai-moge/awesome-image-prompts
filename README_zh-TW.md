### No. 60: 咖啡照片與手繪速寫拼頁

![分類: 攝影 & 影像](https://img.shields.io/badge/%E5%88%86%E9%A1%9E-%E6%94%9D%E5%BD%B1%20%26%20%E5%BD%B1%E5%83%8F-lightgrey)

#### 📚 描述

製作旅行日誌風的雜誌拼版，將咖啡館紀實照片與同一場景的墨水水彩速寫並排呈現。

#### 🌟 提示詞

```
根據提供的參考照片，創作一張統一的雜誌風旅行日誌圖像：將真實的咖啡館瞬間與同一場景的極簡手繪插畫配對，排成精緻的分頁拼版。左側呈現一張溫暖的紀實風格照片，一位咖啡師的手拿著一杯透明玻璃杯裝的冰咖啡，旁邊是專業咖啡機，帶有可見的冰塊、濃郁的琥珀棕色咖啡、逼真的反光、不鏽鋼設備與微妙的咖啡館細節；右側將同樣的構圖重現為在有質感的暖象牙色紙上的隨性復古墨水水彩速寫，保留玻璃杯、手、咖啡機、透視與關鍵細節，使用不完美的黑色線條搭配克制的大地赭色與柔和藍色點綴。運用獨立咖啡館旅行小誌的真實美學、自然的不完美、柔和顆粒感、略微褪色的類比攝影、有觸感的紙張質地、雜誌排版、充足的留白、細小低調的地點/日期/說明文字、平衡的非對稱構圖、懷舊的2020年代旅行日記氛圍、頂級藝術指導、與手作插畫無縫對比的寫實攝影、柔和的大地色調、柔和的自然光、細膩的膠片顆粒、高細節、直式4:5構圖、無logo、無浮水印。
```
