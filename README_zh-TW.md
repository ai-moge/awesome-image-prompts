【主題】 【主視覺主體】 【中文核心字】 【中文標題】 【英文標題】 【對角關係】人物跨角 / 斜向負空間 / 自然邊界 / 地形切面 / 其他 【主色】 【強調色】 【畫面比例】9:16 生成一張具有 \*\*East …

生成一張具有 **East Asian Modernist Exhibition Poster、Japanese Contemporary Graphic Design、Editorial Design** 氣質的現代豎版海報,核心採用「對角構圖」。不要簡單把圖片或文字旋轉 45°,而是先建立一條隱形的斜向主軸,讓主體、自然邊界、色域或負空間從一個角向另一個角推進,使整個版面的視覺重量產生明確方向。

根據【主題】選擇一種最適合的對角機制:人物題材可以讓身體動作從左下伸向右上,以姿態本身形成視覺主軸;極簡題材可以讓大片斜向負空間成為真正主體,只加入極小人物作為尺度參照;自然題材可以利用海岸線、水面、山坡、光影邊界等真實斜向關係切分畫面;地形或建築題材可以用大面積切面、尺度差和留白形成距離感。每張只突出一種主要機制,不要把人物、斜線、色塊和複雜透視全部疊在一起。
