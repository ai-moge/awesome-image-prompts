```

上半部分保留原始照片，保持主體身份、結構、姿態、真實質感、自然光影和原有色彩氛圍，僅進行輕微高級攝影調色，使其具有藝術雜誌、獨立出版物與展覽攝影質感。為適配畫幅，可自然擴展天空、地面或環境背景，但不得拉伸、扭曲或改變主體。

下半部分提取照片中最具識別性的主體、輪廓、姿態與敘事關係，重構為觀察式鋼筆淡彩手稿。不要完整描摹照片，只保留最值得記錄的視覺線索，以最少資訊維持主體身份、比例、方向和場景含義，讓人一眼認出原物，同時保留觀察、刪減與停筆的痕跡。

構圖強調極簡頁面中的音樂性節奏：把主體最重要的輪廓或動作視為一個視覺動機，通過重複、變奏、停頓、重音和突然留白組織畫面。主體不必完整，也不必居中，可偏置、裁切、懸置或向某一方向自然延伸；一兩處較有力量的自由線條承擔視覺重音，其餘線條迅速減弱，讓大片空白像音樂中的休止。避免平均分布和完整填充，使畫面呈現一種克制秩序中的即興、未完成中的完整感。

線條使用纖細、鬆動、不均勻的鋼筆手繪線稿，允許斷續輪廓、尋找線、重複修正、突然加重、輕微偏差和未完成邊緣。局部可以出現更自由、更果斷的長線或快速筆觸，與安靜細線形成節奏反差，但關鍵比例、方向和姿態必須準確。淡彩只用於少數必要位置，從原圖提取2–4種最具辨識度的顏色進行輕薄、透明的局部點染，允許越線、水痕、顆粒和不均勻覆蓋，環境顏色迅速消失。

背景紙色不固定，根據原圖綜合色溫、光線與情緒智能匹配一個極度淺、乾淨、幾乎接近白色的綜合色底，可以微暖、微冷或帶極輕色相，但始終服務於原圖，不形成明顯彩色背景。
```
