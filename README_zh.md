```
打造一张超高级全球旗舰甜点主视觉（KV），融合 Orbit 风格的结构冲击力与 Transit 风格的国际化精致感，围绕一个令人难忘的三段式超级符号展开：一根巍峨的象牙白奶油柱、两片主导性的悬浮樱桃蛋糕，以及环绕其周围悬浮的深勃艮第樱桃点缀星群。精确保留参考图的垂直溅洒雕塑逻辑，同时将其精炼为更干净、更具标志性、更奢华的商业海报。最终画面必须呈现超写实、优雅、诱人且全球顶级的质感，甜点始终是绝对的视觉主角。无标题、无 Logo、无可辨识文字。

核心超级符号构图：
采用严格居中的垂直构图。构建一根高耸的奶油白溅洒柱，如雕塑般的牛奶浪从底部中央升起，以大胆的 S 形曲线向上扭转，并在上半部附近绽放为受控的皇冠状溅洒尖峰。将两片大型主角樱桃蛋糕悬浮于画面中央，正面朝向且清晰可辨，在景深上略微错落但视觉上锁定为一对。在其周围以干净的轨道节奏排列整颗樱桃、樱桃半瓣与少许小液滴，使奶油柱、双蛋糕片与深色樱桃点缀瞬间读作一个完整的旗舰符号。

Orbit 强化：
增强奶油柱的结构力量与纪念碑感。白色溅洒必须升得更高、更具张力，并雕刻出更强的中央剪影，如同一座垂直的甜点图腾。两片主角切片应显得更戏剧性地被托起，并更紧密融入奶油结构，仿佛被一股连续向上的涌动所承载。在形态逻辑上保持动势大胆而爆发，但仍优雅而受控。

Transit 强化：
将整张画面精炼为国际旗舰甜点广告语言。保持色盘更干净、光泽更克制、背景更精致。将奶油高光推向精致的珍珠白与柔和象牙白，而非过于温暖的白。将樱桃色调加深为冷调勃艮第、黑樱桃红与深红宝石，以营造更奢华的全球市场感。最终画面应如同国际奢华食品品牌的顶级烘焙宣传大片。

甜点设计：
将蛋糕呈现为超高级樱桃海绵挞或樱桃茶蛋糕，带有金黄烘焙外壳、柔软的奶油质内里与丰富嵌入的樱桃结构。切片必须显得湿润、柔软、略带密实且刚切好，带有可见的孔隙细节、自然的内里断裂与光亮的果肉囊。蛋糕内的樱桃应显得多汁丰盈，立即强化果味身份。

奶油行为：
奶油溅洒是主要的物理引擎。它必须显得自然丝滑、浓稠、新鲜且物理上可信，带有圆润的边缘张力、优雅的褶皱、真实的黏度、受控的溅洒碎裂与细腻的液滴分离。无虚假的 CGI 僵硬感、无塑料表面、无生硬不自然的溅洒边缘。细尖端可显现轻微半透明，而较厚的块体保持奶油般不透明。

灯光：
采用明亮的高级棚拍灯光，配以柔和的正面主光与左上方微妙强调。蛋糕内里应柔和发光，樱桃应捕捉清晰但克制的镜面高光，奶油柱应呈现带有平滑高光衰减的明亮珍珠白光泽。阴影必须保持柔和、干净且高级，在不显沉重的情况下支撑景深。

材质渲染：
将蛋糕外壳渲染为细致的烘焙纹理与干爽的金黄酥脆；将内里渲染为奶油般的柔软与细腻孔隙；将樱桃皮渲染为紧绷光泽与深沉半透明的果肉密度；将切开的樱桃渲染为多汁的内果肉与糖浆光泽；将奶油渲染为丝绒般的密度与高级流体的顺滑。每种材质都必须显得可触、奢华且物理正确。

色彩系统：
采用一套克制的甜点色盘：珍珠白、象牙奶油、温暖香草米色、金黄蛋糕棕、深勃艮第樱桃、黑樱桃红、红宝石果汁点缀，以及极少量柔和的叶绿。将背景保持为精致的奶油灰褐或温暖石米色调，使白柱与深色樱桃以优雅的旗舰清晰度分离。

背景与洁净度：
采用无缝的高级棚拍背景，无杂乱、无多余道具。将底面保持干净，仅有一层薄薄的奶油池与少许精致碎屑。画面必须显得无瑕、雕塑感十足且适合海报。

动势与收尾：
将场景冻结在优美受控动势的顶峰。樱桃、液滴与碎屑必须显得悬浮于精心设计的向上节奏中，绝不混乱。保留蛋糕内里、樱桃皮、液体边缘与细腻液滴的锐利细节。世界级商业修图、8k、全球旗舰甜点广告品质。

氛围：
标志性、奢华、奶香、果味、雕塑感、精致、诱人、精修、全球顶级、优雅

渲染风格：
超高级甜点广告、全球旗舰烘焙 KV、Orbit 风格中央奶油冲击、Transit 风格国际精致、巍峨奶油白柱、双片悬浮樱桃蛋糕、深勃艮第樱桃点缀、超写实甜点摄影、世界级修图、8k

负面提示：
可辨识文字、Logo、标题、杂乱构图、虚假 CGI 奶油、塑料蛋糕质感、浑浊樱桃色、内里细节薄弱、杂乱道具、脏背景、黑色斑块、破碎的水果解剖、过饱和的红、平板灯光、低分辨率甜点细节、混乱的粒子爆炸
```
