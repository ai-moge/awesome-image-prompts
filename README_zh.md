制作一张高级杂志感食物海报，让真实食物与超大字体发生物理互动并重塑其形态，使用温暖的米白或象牙色背景、粗黑的 Heavy Grotesk 字体、照片级写实的食物材质、充足的留白，以及一套受高端欧式咖啡品牌与当代杂志设计启发的破格编排网格。

食物不可只是与字母重叠或并排放置；把字体与食物当作处于同一个物理世界中的物体，所选互动必须通过可信的物理让字母结构产生明显改变。

示例：PRESS，食物的重量压缩并局部使字体变形；SCOOP，真实的挖勺直接从一个字母上挖走材料，留下相符的凹洞并露出内部可食用的材质；SMEAR，一把刀将食物拖过字体，仅在接触区域造成局部的横向拉伸与剪切；LAYER，字体本身包含真实的食物层，其中一层结构层被物理性地抽出并错位。

让互动保持局部、清晰且物理上可信；未被触碰的字体部分应维持坚硬、干净、几何且易读；每张海报只用一种主要物理机制；避免随机的 liquify 效果、装饰性重叠、通用的 3D 字体或看起来很数码的扭曲。

加入少量编排信息，例如 [INGREDIENTS]、[OPENING HOURS] 与 [ADDRESS]，使用强烈的尺度对比而非传统菜单行；避免长的水平分隔线、方框价格、僵硬的底部信息栏或模板式版面。

主字体使用粗体 Grotesk Sans Serif，产品名称、引言或价格使用高对比的编排 Serif 或斜体 Serif，色彩系统保持极简：米白背景、黑色字体、自然的食物色彩，以及一种强调色。

最终海报应显得聪明、有实体感、高级，且在缩略图尺寸下即刻可懂；核心概念很简单：食物不是装饰字体，而是物理性地改变它。
