生成一张高审美、高信息密度的东方文化展览海报，采用「竖三栏 / 左中右构图」。

重点不是把三个内容分别塞进三个栏，而是先用不等宽三栏建立清晰秩序，再通过主体、图像、线条、空间或无形视觉元素突破栏线，让三个区域重新形成一个完整画面。

可根据主题灵活使用以下方式：

图像越栏：传统绘画、花枝、鸟羽、植物或其他图像主体主要位于一至两个栏位，但局部必须主动突破边界，与其他色栏和 Typography 产生穿插关系。

主体偏置：大型文物、雕塑或人物明显压在其中一侧，另一侧通过年代、材质、档案文字和研究图建立视觉重量。主体可以侵入相邻栏位，但不要机械居中。

现象跨栏：实体主体停留在一侧，让声音、光线、烟气、水纹、运动轨迹等无形元素成为真正连接三栏的视觉线索。线条需要有明确来源、方向和传播逻辑，不要变成科技 UI 或随机装饰。

近中远空间：让三个栏分别承担近景、中景和远景，通过枝条、墙线、水路、石径、建筑轴线或视线连续跨栏，使三个区域看起来属于同一个空间，而不是三张照片拼贴。

三栏比例不要平均，根据主题使用例如 24/30/46、28/22/50、38/34/28 等不同关系。每一栏可以拥有不同背景色、信息密度和视觉重量，但整体必须平衡。

Typography 根据画面内容重新设计。可以使用横向跨栏标题、中等尺度标题、局部反色、图像压字、文字被主体轻微遮挡等方式。不要每张都使用超大单字，也不要固定使用四字纵排或“两字横排 + 两字竖排”。

信息密度参考成熟博物馆海报、艺术图录和 Editorial Design。可加入英文副标题、材质、年代、结构、日期、场馆、策展短句以及少量研究内容。

研究信息应与主题直接相关，例如：文物测绘、纹样放大、材质档案、声学传播、近中远关系、建筑剖面或空间视线。

面积保持克制，作为第二层阅读内容，不要抢主视觉，也不要做成百科或 PPT。

色彩控制在 3–5 个主要颜色。优先使用大面积纯净色域，例如骨白、赭红、朱砂、深青蓝、墨绿、青铜绿等。主体颜色、栏位颜色与 Typography 之间必须形成清楚层级。

核心原则：三栏负责建立秩序，跨栏元素负责打破边界，主体负责视觉重量，信息负责完成作品内容。

整体要求：9:16，高清、清晰、色块干净、主体完整、文字与细线锐利、信息丰富但有秩序，具有真正成熟的文化展览海报与艺术图录完成度。

避免：机械三等分、三个独立卡片、三张图片拼贴感、主体全部困在栏内、固定标题模板、PPT 信息框、科技 HUD、随机跨栏线、无意义小字、过度做旧、斑驳噪点、复杂 UI 和低完成度 AI 海报感。
```

### No. 17: 浓色马克笔人物画

![分类: 插画 & IP形象](https://img.shields.io/badge/%E5%88%86%E7%B1%BB-%E6%8F%92%E7%94%BB%20%26%20IP%E5%BD%A2%E8%B1%A1-lightgrey)

把一张照片画成浓色、手工笔触的马克笔人物画，并配上一句幽默手写文字。

#### 🌟 提示词

浓色马克笔人物画｜把一个真实的人，画成一件有趣的作品 创作任务 以用户上传的照片为唯一人物参考，创作一幅具有当代艺术感的马克笔人物画。 …

<details>
<summary>展开完整提示词</summary>

```
浓色马克笔人物画｜把一个真实的人，画成一件有趣的作品

创作任务

以用户上传的照片为唯一人物参考，创作一幅具有当代艺术感的马克笔人物画。

保留照片中人物的身份、神态、姿势和辨识度，但彻底重新组织颜色、笔触和画面空间。不是给照片套上绘画滤镜，而是像一位有观察力、有幽默感的画家，看过这个人之后，用几支颜色浓郁的宽头马克笔，把这个瞬间重新画出来。

画面应当大胆、浓厚、松弛，有鲜明的手工痕迹。第一眼被大色块吸引，第二眼认出照片中的人，第三眼发现旁边那句有点好笑的手写文字。

一、艺术方向

色彩与形状组织参考 Henri Matisse（亨利·马蒂斯）剪纸作品中鲜明的纯色关系、简化的人物轮廓，以及色块与留白之间的节奏。把这些启发转译为马克笔绘画，而不是制作剪纸拼贴。(泰特艺术馆)

文字与幽默参考 David Shrigley（大卫·史瑞格里）作品中简练的绘画、手写短句，以及对日常生活荒诞之处的观察。只借鉴这种图文之间的幽默关系；本次创作应更温暖，不沿用黑暗、尖刻的语气，也不复制他的具体作品或句子。(NGV)

统一成一种明确的视觉语言：浓色、宽笔、简化造型、真实神态、少量手写旁注。

不要机械混合多种画风。人物不是某位艺术家的固定角色，必须仍然是照片里的那个人。

二、先认出这个人，再简化这个人

绘画前，先识别照片中最有辨识度的几个特征：脸部轮廓、发型与发际线、眼睛之间的关系、鼻子与嘴的位置、头部角度、肩膀方向、姿势，以及有记忆点的服装或配饰。

围绕这些特征组织画面，而不是平均描绘所有细节。

保留人物原本的年龄感、肤色深浅关系、性别呈现与身体特征。保留明显的痣、雀斑、眼镜、胡须，以及帮助辨认身份的少量面部线条。

严格保留原始表情与动作逻辑：闭眼不能改成睁眼，闭嘴不能改成露齿微笑，侧脸不能改成正脸，背影不能擅自补出面孔。头发朝哪个方向散开，身体朝哪里倾斜，都应延续原图。

可以简化解剖细节，但不能通过美化、瘦脸、放大双眼、缩小鼻子，把人物重塑成另一张脸。

幽默主要来自文字和观察，不靠把人物画丑。

三、媒介：浓厚的不透明颜料马克笔

将绘画媒介设定为不透明颜料马克笔，偏丙烯马克笔质感，以宽扁笔头铺色，以中等笔头建立形状，最后用少量细笔完成必要细节和文字。

大色块应饱满、扎实、具有覆盖感，但不要出现油画颜料般的立体堆积。

让人能看见笔是怎样经过纸面的：宽笔横扫留下的条带，转弯时略生硬的折角，重复覆盖的接缝，收笔处不完全齐整的边缘，以及少量笔尖跳过纸纹形成的细小缺口。

大部分色面保持完整，只在局部露出这些痕迹。不要用遍布全图的颗粒噪点代替真实笔触。

先画色块，再补少量线条。不要先用均匀黑线勾出全部轮廓，再像填色本一样填满。

允许局部覆盖、轻微错位和不完全闭合的边界。保留画过的过程，不把每一笔修得完美。

四、用大色块建立人物

把头发、脸、颈部、上衣、手臂和必要配饰，概括成少数几块有重量的形状。形状之间的关系比细碎纹理更重要。

脸部主要由一个基础肤色色面、两三处结构性色块和少量五官笔画构成。取消毛孔、照片微纹理、细碎反光和复杂明暗渐变，但保留支撑身份辨识的面部结构。

眼睛用少量短笔和深色色点完成，眼神方向必须准确。不要统一画成大圆眼，不添加夸张的高光和睫毛。

眉毛用有粗细变化的短笔画出，保留原本的走向和距离。

鼻子可以主要由一块暖色与一两笔暗色提示，不进行精密的立体塑形。

嘴部保留原始开合状态、嘴角方向与情绪。只有原图确实露出牙齿时才画牙齿，并将其概括为简单形状。

头发先画整体轮廓，再添加少量能说明方向的笔画。深色头发可使用深褐、墨蓝或近黑的色块；浅色、灰白色头发保留其辨识度，不一律改成棕发。重要的碎发可以像突然划出的细线，松动人物边缘。

衣服保留款式、领口、层次和关键色彩关系。褶皱只留下解释姿势所必需的几笔。

手势是照片重点时，必须保留动作；手不是重点时，可以减少细节，但不能随意改变位置。

五、色彩：浓重，不沉闷；鲜明，不嘈杂

放弃原提示词中统一的浅粉彩、奶油肤色和淡蓝背景设定。

根据照片里的服装、肤色和情绪，选择一组有限而有力度的配色。通常使用四至六种主要颜色，以一种主导色建立整体气氛，一种对照色制造张力，再用少量强调色点亮画面。

候选色包括钴蓝、群青、朱红、番茄红、赭黄、深草绿、孔雀绿、茄紫、酒红和暖象牙白。每张画只选择适合它的几种，不要把所有颜色同时放进去。

让大面积颜色真正参与构图，而不是只把背景涂得鲜艳、人物仍然保留照片式写实。

肤色允许艺术化转译，可使用赭石、陶土、杏桃或暖棕等色面，并在局部引入与背景呼应的冷色。保留原人物肤色的深浅特征，不统一漂白，也不要把脸切成杂乱的彩虹碎片。

用相邻色块的冷暖与明度差建立体积，不依赖柔焦渐变、喷枪阴影或电影光效。

六、构图与背景

根据原图提取主要人物，删除无关路人、杂物和复杂环境。若是没有明显主次的合影，保留核心人物之间的关系，不任意删掉其中一人。

默认延续原图的横竖方向与关键动作。可以适度裁切、放大和调整主体位置，但不要把有意义的全身动作一律裁成头像。

采用松弛而准确的构图。人物可以略微偏向一侧，为文字留出自然的位置；不要为了对称而机械居中。

背景以一整块主色或两块大的颜色区域构成，可以保留少量暖白纸面。用色块边缘、人物轮廓与空白之间的关系创造空间，不还原完整的摄影环境。

只有当某个物件直接构成照片的趣味或人物特征时，才保留它，例如手中的杯子、被风吹起的帽子、怀里的宠物。把它同样画成简洁色块。

不要无意义地添加植物、星星、爱心、贴纸或几何装饰。画面需要的是取舍，不是堆满设计元素。

七、手写文字：像画家看着这个人，忍不住写了一句

先理解照片中真实可见的动作、表情、衣物或物件，再创作与之对应的幽默短句。

文字应当让人觉得：“这句话是看过这张照片才想到的。”

采用轻微反差、一本正经的玩笑、拟人化的小抱怨，或日常生活中的微小荒诞。不要直接说明照片里有什么，也不要使用励志鸡汤和与画面无关的流行口号。

英文为主，可酌情加入一句更短的中文；不必逐句双语翻译。主句控制在三至八个英文单词，另可添加一个一至三个单词的小旁注。除日期外，文字最多形成两组。

以下仅示范幽默机制，不是固定文案，不要全部写入画面：

头发明显凌乱时，可以写：
“MY HAIR HAS OTHER PLANS.”
人物认真拿着一小杯饮料时，可以写：
“SMALL CUP. BIG RESPONSIBILITIES.”

人物明显望向远处、呈放空姿态时，可以写：
“CURRENTLY BETWEEN THOUGHTS.”
必须根据实际照片重新判断和创作。没有对应的画面线索就不要使用这些句子，也不要为配合句子给人物添加道具。

幽默针对情境，不贬损人物外貌或身份。照片气氛庄重时，让文字更轻、更含蓄，不强行制造笑点。

### No. 51: 植栽混凝土Logo装置

![分类: 品牌设计 & 界面](https://img.shields.io/badge/%E5%88%86%E7%B1%BB-%E5%93%81%E7%89%8C%E8%AE%BE%E8%AE%A1%20%26%20%E7%95%8C%E9%9D%A2-lightgrey)

#### 📚 描述

把任何品牌Logo变成嵌入原始混凝土墙、以自定颜色茂密活体枝叶填满、置于直射阳光下的写实户外装置。

#### 🌟 提示词

[ 品牌名称 = \_\_\_\_\_\_\_\_\_\_\_\_\_] [ 材质颜色 = 鲜艳的酸性黄绿色 chartreuse] 使用一套内凹式活体植栽混凝土镶嵌系统，制作写实的建筑可视化。 核心视觉系统 …

```
[ 品牌名称 = _____________]

[ 材质颜色 = 鲜艳的酸性黄绿色 chartreuse]

使用一套内凹式活体植栽混凝土镶嵌系统，制作写实的建筑可视化。

核心视觉系统

把来源转化为直接切入一整面大型原始浇筑混凝土墙的永久建筑装置。

决定性的概念不是用苔藓做的Logo，不是放在墙上的植物，也不是传统的3D挤出徽章。

可辨识的来源几何必须以一个浅的负空间种植凹槽存在，物理性地内凹进混凝土表面，并密集填满数百片小小的活体叶子。

结果应像一座在直射自然光下拍摄的真实户外建筑品牌装置。

结合三套系统：

1. 精确可辨识的来源几何；
2. 巨大且风化的浇筑混凝土建筑；
3. 从内凹几何内部生长出的浓密活体植物材料。

来源优先

若 [来源模式 = LOGO]：

自动辨识 [品牌名称] 最可辨识、最真实的官方独立符号。

保留其标准轮廓、比例、曲线、笔画关系、交叉、反白形、内部负空间与构件间距。

不要重新设计、简化、拉伸、圆化、重新诠释或以通用方式近似该识别。

只要存在独立符号，就使用它。

除非某文字商标、注册符号、商标符号或次要品牌确实属于所提供的识别且在构图上必要，否则不要自动加上。

忽略Logo原生的颜色。植物材料遵循 [材质颜色]。

若 [来源模式 = 附加图片]：

把附加图片作为唯一的来源结构。

保留主导的可辨识主体、轮廓、姿态、比例、方向、主要内部形状与整体构图。

把主体翻译成同一套内凹植栽建筑系统，而不是把原始照片贴到墙上。

在正常观看距离维持即时可辨识。

形态与构造

把混凝土墙当作一整块巨大连续的建筑板。

把精确的来源轮廓向内切入混凝土，作为一个浅的种植凹槽。

凹陷应具有可信的物理深度，约为来源几何特征笔画宽度的4–8%。

不要把Logo向外挤出。

不要做成凸起的牌匾。

不要加上独立的外框。

混凝土前面在来源周围必须保持完全平坦。

凹腔应具有：

— 干净的垂直或微微收窄的内部混凝土壁；
— 真实的材料厚度；
— 极度克制的边缘圆角；
— 微小、自然磨损的混凝土微倒角，而非装饰性倒角；
— 一层深色内凹的生长基质，只透过叶子间偶尔的缝隙可见；
— 凹腔内部强烈的接触阴影。

把所有真实的负空间与反白形保留为未受触动的混凝土。

即使植被本身是有机的，来源轮廓仍必须保持几何上的纪律。

植物构造

用数百片可个别辨识的小活叶填满内凹的来源几何。

使用紧凑的观赏性攀爬叶材，其物理尺度类似迷你常春藤、薜荔、黄杨新芽或浓密的建筑地被。

避免大型热带叶。

避免草。

避免蓬松的苔藓。

避免均匀如地毯的植被。

每丛植物应包含多根茎与叶，并在以下方面有细微变化：

— 尺度；
— 方向；
— 曲度；
— 重叠；
— 高度；
— 旋转；
— 密度。

维持高叶密度，使来源在远处读作连续的植物体块。

近看时，该体块必须分解为许多独立的叶子，而不是单一的程序化绿色材质。

让约85–95%的叶子保持在真实的来源轮廓之内。

允许克制的5–15%叶与茎自然地突出于选定的边缘、角落与开口之外。

这种蔓生必须是不对称且局部的。

不要用失控的植被破坏来源轮廓。

在少数结构接合处与下缘附近制造稍浓密的植物生长，同时偶尔留下微小的深色缝隙，露出下方内凹的基质。

材质颜色

植物材料属于 [材质颜色] 家族。

不要把 [材质颜色] 当作平坦均匀的颜色来套用。

在该家族内制造自然的色调变化：

— 阴影丛内部更深更暗的版本；
— 大多数叶子上的主要 [材质颜色]；
— 面向阳光的叶子稍暖或稍亮；
— 偶尔的浅色边缘高光；
— 个别叶子之间轻微的饱和度变化。

即使 [材质颜色] 不寻常，材料仍必须在物理上表现得像真实、薄的活体叶子，而非涂漆的塑料。

混凝土材质

使用真正的建筑浇筑混凝土。

基调：中性至略暖的浅灰。

表面粗糙度约0.75–0.9。

混凝土应干燥、矿物质且几乎完全漫射。

引入克制的真实世界瑕疵：

— 细孔；
— 浅针孔；
— 微观矿物颗粒；
— 淡淡的斑块；
— 微妙的变色；
— 偶尔的磨损；
— 微小的崩缺处；
— 极细的发丝状痕迹；
— 轻微累积的风化；
— 一两道宽阔的施工或模板接缝。

让这些细节保持低对比。

不要把墙变成破旧的grunge风。

混凝土应感觉自然老化、饱经风雨，而非人工加上纹理。

叶子着色

每片叶子都应具有可信的薄有机材料反应。

使用中等哑光的蜡质叶材：

— 粗糙度约0.35–0.55；
— 克制的宽广镜面反应；
— 微妙的半透明；
— 极薄的受阳边缘有轻微透光；
— 细致的自然表面变化；
— 无塑料光泽。

面向阳光的叶子可能明显比阴影中的叶子更亮。

内部叶子应落入深绿或由 [材质颜色] 衍生的阴影色调。

光照

使用真实的户外建筑日光。

主光是一个直接的硬质阳光光源，位于墙面相对于相机的右／前上方高处，以斜角打在墙上。

阳光必须从每一片突出的叶与茎产生清晰的方向性阴影。

这些小小的植物阴影至关重要。

它们应明显落在周围的混凝土上，并揭示每株植物从凹陷中突出多远。

使用微弱而宽广的自然天空补光，约为主光强度的20–30%。

维持约4:1至6:1的高主光对补光比。

不要压平阴影。

不要使用商业摄影棚柔光箱。

不要使用轮廓光布置。

不要使用霓虹灯光。

环境阴影

引入几道大尺度、不规则的阴影，来自画面外看不见的植被、树枝或建筑性叶群。

让这些宽广的有机阴影斜向横越混凝土表面。

它们应远大于来源本身，并部分与构图重叠。

其边缘可依离墙距离从中等锐利到略微柔化不等。

这些环境阴影必须感觉是偶然的、由直射阳光自然造成的，而非设计成的图形叠层。

阴影深度与环境遮蔽

使用强烈但物理可信的接触阴影：

— 密集重叠叶子之间的深阴影；
— 茎从基质冒出处的克制环境遮蔽；
— 凹腔边界部分位置的深色狭缝状阴影；
— 内部角落增强的遮蔽；
— 叶子投射到混凝土上的个别阴影。

最暗的数值应主要存在于内凹凹腔内部与浓密叶子下方。

不要用人工黑色描边勾勒来源。

反射

混凝土几乎不应显示任何可读的镜面反射。

其反应宽广而漫射。

叶子可在阳光打到其弯曲表面处，产生小而柔和的蜡质镜面高光。

无铬金属反射。

无HDRI条纹。

无人工反射板。

无发光高光。

相机

几乎完全正面拍摄这面墙。

让相机光轴接近垂直于混凝土表面，仅带极其微妙的自然建筑透视。

使用约45–60mm全画幅镜头的视觉特性。

避免广角变形。

避免夸张的透视收敛。

来源几何应在视觉上接近其标准的2D比例。

相机高度大致对齐装置的垂直中心。

墙本身应主导整个背景，并延伸超出每一个画面边缘。

构图

正方形1:1画面。

把可辨识的植物来源放在视觉中心附近，若真实几何需要则带轻微的自然不对称。

让它占据约55–65%的画面宽度。

在它周围保留大量裸露的混凝土。

不要裁切掉来源的重要部分。

不要让装置漂浮。

它是物理性地雕刻进墙内并由墙支撑。

影像应感觉像一座在现场拍摄的大型永久户外装置，而非在摄影棚拍摄的小型装饰物。

景深

使用深的建筑景深。

约相当于f/8–f/11。

让以下清晰解析：

— 混凝土表面；
— 凹陷边缘；
— 大多数叶子；
— 环境纹理。

只有最近与最深叶子之间极小的景深变化可微妙地柔化。

无微距散景。

无广告式浅景深。

渲染性格

具有物理合理路径追踪材料表现的写实建筑摄影。

自然的动态范围。

强烈的直射阳光，但保留高光细节。

浓密且有物理依据的接触阴影。

细致的混凝土微纹理。

个别解析的叶子。

微妙的光学不完美，而非无菌的CGI完美。

最终影像最初应读作干净可辨识的识别，只有在近看时才揭示复杂的活体植物构造。

负向约束

不要做普通的3D挤出Logo。

不要把绿色Logo放在混凝土上面。

不要用独立的花箱。

不要做有外框的绿墙。

不要用蓬松的苔藓。

不要用草。

不要用人工草皮。

不要用大型丛林植物。

不要用植被覆盖整面墙。

不要遗失真实的来源几何。

不要填满真实的内部负空间。

不要制造过度失控的蔓生。

不要用完美重复的程序化叶子。

不要让植被看起来像塑料。

不要用平坦的绿色纹理填充。

不要加装饰性描边。

不要做厚而圆的Logo倒角。

不要用有光泽的混凝土。

不要加霓虹辉光、bloom、雾、戏剧性体积光或人工电影效果。

不要做摄影棚背景。

视觉力量必须来自精确的几何、原始矿物质混凝土、活体植物的复杂性、直射阳光与物理上令人信服的投影。

### No. 53: 蜡粉笔手绘风九宫格表情包贴纸页

生成一张 3×3 透明贴纸页，中间为人物真实去背版，周围八张为同一人物的蜡粉笔手绘表情包。

#### 🌟 提示词

请严格参考我上传的人物原图，制作一张 \*\*1:1 正方形透明贴纸页\*\*。 【画面结构】 - 整张画面由 \*\*9 个独立贴纸\*\* 组成； - 按 \*\*3×3 网格\*\* 排列； - 九个贴纸之间保留 …

```
请严格参考我上传的人物原图，制作一张 **1:1 正方形透明贴纸页**。

【画面结构】
- 整张画面由 **9 个独立贴纸** 组成；
- 按 **3×3 网格** 排列；
- 九个贴纸之间保留 **较宽且完全透明的间隔**；
- 整张贴纸页背景必须透明；
- 不要生成额外背景，不要做成整张连续插画，不要让贴纸相互重叠。

- 严格保留原图人物的身份特征、脸型、五官、发型、发色、肤色、服装关键特征和整体气质；
- 可以做轻微优化，如提高清晰度、优化边缘、微调质感；
- 不要改变人物身份，不要换脸，不要让不同贴纸像不同的人。

- **中间第5格** 固定为原图人物的抠像版；
