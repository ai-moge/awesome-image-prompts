```
主题：生日
用途：官网/菜单
配色：马卡龙色

请按上述设定，使用图像生成功能，制作12个「在色块上加画手绘线条、轻松自然的图标」，并将以下图标组输出为一张PNG图片。

【画法】
用稍带圆润、简单的色块表现主体，再用较深的笔在其上补画特征。

不要把轮廓全部框起来，只画出传达形状所需的部分轮廓与最少的内部线条。让色块与线条各自承担形状的一部分。

【主题与统一感】

象征主题的装饰元素，只加在其本身可爱、能自然融入的地方。不必每个图标都放。

统一线条粗细、形状圆润度、简化程度，以及色块与线条的平衡，让它们看起来像同一位绘者的系列。

【排版】
以4列×3行的等间距网格排列。每个图标居中，大小约为格子的一半，视觉大小一致，并留出宽松的间距与外侧留白。

背景为白色。不加文字、边框、阴影、渐变与质感。

若有种类或数量的指定则优先采用，并实际生成图片。
```
