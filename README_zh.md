```
高级商业产品主视觉摄影。

若用户提供产品实拍图、包装图或商品参考图，以原产品为最高优先级视觉依据。准确保留产品的造型、比例、结构、包装、品牌标识、文字位置、颜色、材质、纹理及关键识别特征，不擅自改款、重新设计或替换商品。可以根据新场景自然重建光线、阴影、反射、透视与环境色，使原产品真正融入画面，而不是简单贴图。若原图背景杂乱，可自然提取主体并重新建立空间。

画面从商品自身向外生长。主体清晰、真实、有重量，表面纹理、边缘和材质具有可信触感；商品自然落在与其气质相呼应的承载基面、台面或结构关系中，形成明确重心与接触阴影，避免悬浮感和模板化展台。

前景与周围只出现真正能够解释商品的器物、原料、材质或细节，疏密自然；背景保持克制，可通过柔和渐变、低对比轮廓、自然投影、模糊形态、纹理或若隐若现的主题意象建立空间，让环境像商品气质留下的余韵，而不是直接堆砌主题元素。

整体高级、安静、真实、有空气感，丰富但不过满，元素之间彼此牵引而非人为堆积。避免商品变形、包装文字乱改、品牌元素丢失、漂浮主体、廉价展台、机械对称、无意义装饰、平均打光、背景抢戏及模板化电商感。

最终呈现成熟品牌级电商主图、产品海报或品牌KV。
```

#### 📚 描述

打造高端时尚编辑海报，模特置身于由巨型立体字体与透视构成的空间中，配以硬朗阴影和一枚高饱和色标。

```

[背景]：{暖灰／炭灰／水泥灰／柔和灰褐}

[强调标签]：{BEND / BEYOND / TURN / AXIS}

制作一张高端时尚编辑海报，主体置身于由字体构筑而成的空间中。

使用一位成年时尚主体，具备真实的肤质与发丝、干净修长的轮廓、单色定制服装、具立体感的棚拍打光，以及克制却富雕塑感的姿势。

以超大、超窄的无衬线字体横跨多个空间平面来构筑版面。结合实心字母、细描边字母、裁切形状与强烈透视变形。字体应出现在不同表面或不同方向，在主体周围营造真实的深度。

以[空间手法]作为主要概念：
• 折叠面：字体沿着墙面、转角或地面平面弯折。
• 分层透视：不同深度上的多个字体平面。
• 字体与阴影：大型字母与主体都投下强烈阴影。
• 旋转字体面：大型字母面板以不同角度环绕主体旋转。

使用清晰的方向性棚拍灯光，让主体具有体积感，空间中含有可辨的阴影。让阴影与字体及地面互动以强化深度。

背景保持极简且具建筑感。仅加入少量有意义的微文案，以及一枚含[强调标签]的小型高饱和[强调色]标签。

维持强烈层次：一个主字、一个主体、一层次要描边字体、一枚小型彩色标签，以及清晰的空间透视感。

最终影像应具备大胆的编辑式艺术指导感：图形化、摄影感、空间感，且能让人停下滑动。
```
