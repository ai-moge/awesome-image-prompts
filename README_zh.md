```
Orbit 方向：

Transit 克制：
将一切简化为仅剩必要的奢华结构：暗色背景、雕塑感丝绒、一条项链、极简标志、一句短标题。移除所有不必要的描述性文案与装饰杂乱。最终海报应以极致的清晰与从容的自信，瞬间被解读为旗舰级珠宝视觉。

灯光：

材质渲染：

字体与品牌：
在顶部中央，放置一个极简的奢华标志与品牌名「VELORIA JEWELS」。加入一行极小的说明文字：「High Jewelry」。在底部中央附近，仅放置一句短的编辑式标题：「Rare Light, Quietly Held」。字体应稀疏、优雅且次于产品，以柔和象牙白或淡银白色呈现。

色彩系统：
深炭黑、酒红丝绒、白钻火彩、冷调铂金或白金反射，以及一抹克制的祖母绿。饱和度须保持克制、奢华且情感丰富。

风格：
戛纳级奢华珠宝广告、超高端编辑静物、戏剧性极简主义、旗舰品牌广告、收藏级画质、隽永、优雅、电影感、全球可营销。

画质与物理限制：

负面提示：
```

生成一张 9:16 城市概念海报，把同一座城市的两种面貌压进同一画面，两侧城市世界对望并融入主标题。

```
画面建立两个彼此对望的城市世界：A 侧从画面一侧向中央密集生长，B 侧从另一侧向中央延伸，两侧拥有各自完整的建筑、道路、交通、人物和城市生活细节。通过夸张但可信的空间关系，让城市像从两个方向共同挤压、包围中央区域，形成强烈尺度感、纵深感和城市奇观。

两侧不能只是换颜色，而要通过建筑语言、时代特征、地理环境、交通方式、生活细节和光线真正体现【城市面貌 A】与【城市面貌 B】之间的关系。每一侧设置一个清晰的主视觉地标，其余城市元素逐级退后，形成近景、中景、远景和完整城市天际线。

中央保留一条较窄的天空、雾气、水域或城市裂隙作为视觉缓冲，两侧环境可适度伸入中央，使画面紧张但不混乱。整体采用高密度细节 × 清晰视觉层级，远看具有冲击力，近看能够发现有意义的城市信息。

重点：让海报首先是一件完整的城市视觉作品，每一个建筑、文字、色彩和细节都服务于城市主题，而不是模板化填充。
```

#### 📚 描述

一套灵活的万能提示词模板，只需替换结尾主题，即可为各种题材生成具文化气质的编辑式海报。

```
根据输入主题，创造一幅具有鲜明文化气质与当代编辑意识的视觉作品。不要套用现成模板，也不要机械复制某种固定版式，而是从主题自身的情绪、年代、语义、人物关系、物质质感与文化线索中，自然生长出画面的秩序。

首先辨认主题中最值得凝视的核心元素：它可以是人物、物件、建筑、自然形态、符号、局部细节或抽象形象。让它成为画面的精神重心，但不必永远居中、完整或宏大；可以偏移、裁切、隐藏、留白、重复、缩小或突然逼近。文字不是附着在图像上的说明，而应像另一种视觉材料，与主体彼此靠近、避让、穿插、呼应、压迫或保持距离，使阅读顺序与观看路径自然形成。

构图应具有克制而自由的张力，在整齐与偶然、密集与空旷、稳定与轻微失衡之间寻找恰当状态。允许大面积安静区域，也允许局部突然聚集；让标题、日期、注释、手写痕迹、印章、编号、细小信息等依据主题形成不同层级，不追求平均分布。

色彩从主题气质中产生，可以沉静、明亮、单纯、复杂、温暖或冷峻，但始终保持明确的综合色调与少量关键色之间的关系。字体、字重、尺度、方向、间距与语言形式应随内容改变，既有编辑设计的精确，也保留人工判断留下的微妙不规则感。

画面应具有真实印刷品、文化出版物、展览视觉或独立艺术海报的质感：清晰、克制、耐看，细节丰富却不过度装饰。最终作品不是在解释主题，而是在主题周围建立一种可停留、可联想、带有余韵的视觉空间，让信息、形象与空白共同完成表达。
```
