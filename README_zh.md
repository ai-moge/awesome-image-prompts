生成一张具有强视觉冲击和高级文化展览气质的「中轴夹景」海报。

先建立一条明确、稳定的垂直中轴，再让【左侧主体】与【右侧主体】从画面两侧共同形成视觉重量，把主标题、人物、植物或留白区域推向中央。

左右主体必须足够大，靠近画面边缘并允许自然裁切，共同承担主要视觉重量。两侧可以在轮廓、大小、颜色、材质和细节上不同，但整体视觉重量必须平衡，避免简单复制和机械镜像。

根据主题选择不同的夹景方式：

织物、植物等柔性材料可通过自然弯曲形成柔性夹景；
