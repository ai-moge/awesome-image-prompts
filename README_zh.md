根据【主题】选择一种最适合的对角机制:人物题材可以让身体动作从左下伸向右上,以姿态本身形成视觉主轴;极简题材可以让大片斜向负空间成为真正主体,只加入极小人物作为尺度参照;自然题材可以利用海岸线、水面、山坡、光影边界等真实斜向关系切分画面;地形或建筑题材可以用大面积切面、尺度差和留白形成距离感。每张只突出一种主要机制,不要把人物、斜线、色块和复杂透视全部叠在一起。
