### No. 2: 照片变身手作饼干套装

#### 📚 描述

将 3:4 画面上下对半分割，上半是原照片，下半是忠实还原主体的朴实手作迷你饼干套装与量身设计的包装。

#### 🌟 提示词

仔细逐一观察每张上传的照片，并把每一张变成一张独立的设计海报。不要把多张照片拼成拼贴。永远每张照片输出一件作品。 整体格式为 3:4 竖版构图。将画布水平方向精确对半分割，上 50%、下 50%。 上 50% = …

```
仔细逐一观察每张上传的照片，并把每一张变成一张独立的设计海报。不要把多张照片拼成拼贴。永远每张照片输出一件作品。

整体格式为 3:4 竖版构图。将画布水平方向精确对半分割，上 50%、下 50%。

上 50% = 原始照片
下 50% = 一组受照片启发的小型手作饼干

【上半｜原始照片｜最重要】

原封不动地使用原始照片。

不要把人物、猫、狗、动物、建筑、花、食物、物件、风景或任何其他主体换成别的东西。准确保留脸部、表情、眼睛、耳朵、发型、毛色、花纹、体型、姿态、姿势、服装、随身物、朝向、色彩、光线与整体氛围。

仅在必要时自然延伸背景。不要扭曲或更改主体本身。

【下半｜小型手作饼干组】

仔细观察原始照片，选出一个最能代表该图像的主体。

做出一个重现该主体的“主体饼干”，再加上 2–4 个自然受照片主体、地点、季节、事件或氛围启发的“相关迷你饼干”，整组约 3–5 个小饼干。

例如若主体是猫，就做出猫本身，再加上鱼、零食、毛线球、脚印或玩具等，挑选最适合那只特定的猫与那张照片的元素。

不要每次都用同样的组合。为每张照片单独设计内容。

【最重要｜不要把主体一般化】

不要把主体饼干换成“通用的猫”“通用的狗”“通用的人”或其他一般化版本。

饼干必须代表原始照片中确切的那个个体、动物或物件。

特别留意:

* 脸型
* 表情
* 眼型
* 耳朵形状与角度
* 发型
* 毛色与花纹
* 体型
* 朝向
* 姿态与姿势
* 具辨识度的随身物或配件

尽可能让这些细节与原始照片相符。

对猫而言，仅能被辨认为“一只猫”是不够的。与上方照片相比时，最高优先是让人感觉:

“这就是这只猫！”

若主体为侧脸，就保持侧脸；若看起来想睡，就保留困倦表情；若是坐着，就重现同样的坐姿。不要擅自转成正面或改成别的姿势。

【如何制作饼干】

不要把照片印在饼干上。

而是把饼干切成主体与各主题的实际形状。

不要只是在普通圆饼干上画褐色线条。

用手作饼干实际可行的方式重现特征，例如外轮廓、浅浮雕细节，以及面团颜色的自然变化。

【朴实手作感】

所有饼干都应相当小，为迷你尺寸。

不要做得像量产品那样完美光滑。保留以下细节:

* 略不平整的轮廓
* 细微的变形
* 不对称的形状
* 不均匀的厚度
* 细小的裂痕或气泡
* 圆润的边缘
* 烘烤色泽的自然变化

它们不该看起来像失败的饼干，而应带有一片片手工裁切与烘烤的迷人不规则感。

然而，手作质感不得把主体的脸部或辨识特征扭曲到看起来像别的主体。

【包装｜每张照片都要更换】

把 3–5 个迷你饼干一起装进一个小包装。

不要为包装使用固定的颜色、图案、材质、绳子或小标签。依原始照片自动设计。

从主体的毛、衣物、花、风景、季节、天空、光线或点缀色等元素中提取 2–3 种颜色，转化为柔和、略微降低饱和度的色盘。

若使用图案，做成受照片启发的小主题、低调的手绘风图案。不要印上照片本身。

选择适合该照片的包装材质，例如:

* 透明袋
* 半透明的玻璃纸
* 蜡纸
* 自然的米白薄棉纸
* 小纸袋

保留手工包装的温度，带有自然的褶皱、略不均匀的折线与些微错位。

【最重要｜不要装饰背景】

下半的背景只能由与照片调和的极淡素色纸构成，例如:

* 奶油白
* 象牙白
* 自然米白
* 浅米色
* 淡灰白

不要在背景加入任何花、植物、盘子、道具、缎带、纸屑、图案、插画或其他装饰。

那里除了包装好的饼干组之外不应放置任何东西。留下大量留白。

【最重要｜让整组保持小巧紧凑】

不只是饼干，含包装在内的整组都应显得相当小。

作为参考，整个包装只应占下半宽度约 25–30%。不要放大到填满下半区域。

构图应像是一个小包裹随意放在一片宽广素色留白的中央附近。

这个小包裹应显得小巧、柔软、略微饱满，几乎像是被随手放在那里。

它可以略微倾斜，里面的迷你饼干可以自然重叠。但主体饼干的脸、形状与辨识特征仍应清晰可辨。

使用柔和自然光，只带极淡的接触阴影。不要让包裹悬浮在半空。它应显得自然放在真实的纸上。

【最终图像】

上 50% = 原封不动的原始照片
下 50% = 与照片高度相似的主体饼干 + 受照片启发的相关迷你饼干 + 专为该照片设计的定制包装

主体应具有与原始照片相同的脸部、表情、朝向、姿态与辨识特征。

饼干应小巧、略不平整、朴实且手作。

包装应依每张照片改变颜色、图案与材质。

背景必须保持完全简单素净。

整组应相当小，紧凑地置于大量留白之中。

将上方照片与下方饼干相比时，完成的作品应让观者感觉:

“这张照片被直接变成了一组小小的手作饼干！”

### No. 3: 黑白流体纤维 Logo

#### 📚 描述

在保留原始轮廓的前提下，将 Logo 转化为黏稠光泽纤维的微距浮雕，严格黑白呈现。

#### 🌟 提示词

```
[材质颜色＝严格黑白]
[来源模式＝附加图片]
使用连续的黏性纤维流浮雕系统，创作出极具触感的微距视觉化。

完全保留所附参考图的原样—相同的轮廓、比例、几何、间距与可辨识的细节。不得重新设计、扭曲、简化或修改形状。

主体形状必须为深黑色，并带有一条清晰、连续的纯白轮廓线，精确沿着其外缘。不得有文字或额外元素。
