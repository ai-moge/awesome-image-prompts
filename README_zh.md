下半部分提取照片中最具识别性的**主体、轮廓、姿态与叙事关系**，重构为一具**中国传统皮影戏偶 / shadow puppet**，在一面被暖光照亮的半透明宣纸幕布上演出。无论原图是人物、动物、建筑、植物、器物还是风景，都被理解为一个“可以被操纵的角色”：主体被拆分为少量关节部件，以铆钉相连，姿态取自原照片中最有表情的那个瞬间，并配有一两根细长的操纵竹签自画面下方伸入。
