### No. 2: 荧光黄知识档案海报

![分类: 创意视觉](https://img.shields.io/badge/%E5%88%86%E7%B1%BB-%E5%88%9B%E6%84%8F%E8%A7%86%E8%A7%89-lightgrey)

#### 📚 描述

生成一张竖版实验性杂志封面海报，融合黑白科学图鉴、巨大中英文编辑排版与平面荧光黄色块，构成知识档案版面。

#### 🌟 提示词

你是一位擅长实验性出版物、文化杂志封面与知识型海报的资深平面设计师。 请围绕本提示词最后给出的【创作主题】，设计一张具有“知识档案、科学图谱、编辑设计、东方文字与现代主义排版融合”气质的竖版视觉作品。 …

```
你是一位擅长实验性出版物、文化杂志封面与知识型海报的资深平面设计师。

请围绕本提示词最后给出的【创作主题】，设计一张具有“知识档案、科学图谱、编辑设计、东方文字与现代主义排版融合”气质的竖版视觉作品。

这不是普通插画，而是一张经过严密编辑和信息策划的杂志封面或文化海报。作品需要让人感觉像某个虚构研究机构、知识社群、学术俱乐部或独立出版物发行的专题刊物。

━━━━━━━━━━━━━━━━━━
一、主题转译逻辑
━━━━━━━━━━━━━━━━━━

首先分析【创作主题】的核心概念，并自动提炼：

1. 一个最具代表性的“主题主体”；
2. 两到四个与主题相关的次级物件；
3. 一个可以被剖析、拆解或标注的结构；
4. 一个具有象征意义的自然物、器官、机械零件、植物、昆虫、建筑或历史器物；
5. 若干能体现主题关系的箭头、坐标、比例、轨迹、连接线、编号与注释。

不要直接用常规商业摄影表现主题。

将主题内容转译成以下一种或多种视觉形式：

科学图鉴、古典百科全书插图、植物学图谱、昆虫学标本、人体解剖图、机械专利图、工程结构图、天文轨道图、考古档案、医学插图、地理测绘图、自然史铜版画、实验室观察记录、博物馆藏品登记图。

所有图像元素都必须与【创作主题】存在概念联系，不能只是无意义装饰。

━━━━━━━━━━━━━━━━━━
二、整体版式
━━━━━━━━━━━━━━━━━━

画面比例为竖版杂志封面或文化海报，建议 4:5、3:4 或接近 A 系列纸张比例。

使用严谨但被故意打破的现代主义编辑网格：

- 整体采用非对称构图；
- 大面积保留浅灰白色负空间；
- 信息集中在几个不同密度的区域；
- 局部非常拥挤，局部极度空旷；
- 元素不需要全部居中或对齐；
- 部分图像、文字、线条被页面边缘裁切；
- 让画面像一张仍在研究和编辑中的知识档案；
- 保持“理性秩序”与“受控混乱”同时存在。

画面中加入一个醒目的荧光酸性黄色矩形色块，占画面约四分之一至三分之一。

黄色色块可以偏离中心，作为视觉锚点。主标题、科学图像和注释线可以局部压在黄色色块之上，也可以穿越色块边界。

黄色色块不要做成立体物体，不使用阴影、渐变和高光，只使用纯平面印刷色。

━━━━━━━━━━━━━━━━━━
三、文字层级
━━━━━━━━━━━━━━━━━━

建立强烈的编辑文字层级：

1. 一个超大号中文主标题；
2. 一个较大的英文衬线体或高对比度斜体英文副标题；
3. 一个期号、年份、章节编号或档案编号；
4. 若干极小字号的中文与英文注释；
5. 少量竖排文字、边缘文字、页码、索引、坐标或档案信息；
6. 若干短横线、点线、分隔线、下划线和栏目标记。

中文主标题直接根据【创作主题】生成，文字简短、有力量，建议为二至八个汉字。

主标题使用具有书籍感、文学感、印刷感的中文宋体、明朝体或高对比度衬线字体。字号极大，可被裁切，可与图像重叠，但必须保持清晰的视觉主导地位。

英文文字采用优雅、纤细、高对比度的 Didone 风格衬线体、古典斜体或编辑字体。

辅助文字可以非常小，像研究注释、出版信息、脚注和图鉴说明。文字首先承担构图功能，其次才是阅读功能。

不要使用圆润可爱的字体、科技霓虹字体、游戏字体、卡通字体或普通无衬线商业广告字体。

生成模型无法准确书写文字时：

- 主标题只保留简短的【创作主题】；
- 其余小字表现为整齐、可信的排版纹理；
- 不生成乱码式大标题；
- 为后期排版预留干净区域。

━━━━━━━━━━━━━━━━━━
四、图像语言
━━━━━━━━━━━━━━━━━━

主要图像采用黑色单色线描，具有十九世纪科学图鉴和博物学铜版画的质感：

- 精细钢笔线描；
- 蚀刻线；
- 交叉排线；
- 点描；
- 木刻或铜版画质感；
- 黑白科学插图；
- 旧百科全书图像；
- 解剖式结构；
- 精密但略显陈旧的印刷线条。

选择一个最重要的主题图像作为主体，占据较大面积。

再加入三至六个较小的辅助图像，例如：

- 局部放大结构；
- 切面图；
- 运动轨迹；
- 标本图；
- 细节零件；
- 微观结构；
- 不同生长阶段；
- 不同观察角度；
- 概念关系示意；
- 象征性生物或器官。

图像之间用极细的指示线、箭头、圆形标记、比例尺、坐标线和编号建立关系。

可以加入少量：

- 手写记号；
- 研究者批注；
- 圆圈；
- 十字定位符；
- 裁切标；
- 测量线；
- 标本编号；
- 几何辅助线；
- 乐谱或统计波形；
- 虚构出版标识。

但不要堆积无关装饰。每一种视觉符号都应强化“研究、观察、分类、连接和思考”的感觉。

━━━━━━━━━━━━━━━━━━
五、色彩系统
━━━━━━━━━━━━━━━━━━

严格限制色彩：

- 背景：略带纸张质感的浅灰白色或旧书纸白色；
- 主色：纯黑色；
- 强调色：高亮度荧光黄色、酸性柠檬黄或印刷黄；
- 辅助色：极少量中性灰。

画面中不出现其他明显彩色。

整体黑色约占视觉信息的主要部分，黄色只作为强烈、克制的视觉信号。

避免金色、橙色、蓝色、红色、紫色及多彩渐变。

━━━━━━━━━━━━━━━━━━
六、印刷与材质
━━━━━━━━━━━━━━━━━━

让作品具有真实独立出版物的印刷触感：

- 轻微纸张纤维；
- 轻微复印机噪点；
- 油墨不均匀；
- 套印误差；
- 半色调颗粒；
- 局部墨迹偏重；
- 微小划痕；
- 边缘裁切痕迹；
- 旧档案扫描感；
- 少量污点；
- 微弱折痕；
- 胶印或丝网印刷质感。

质感必须克制，不要做成严重破损的复古海报，也不要覆盖主体信息。

画面保持平面化、纸面化、编辑化，不制造真实三维空间。

━━━━━━━━━━━━━━━━━━
七、视觉气质
━━━━━━━━━━━━━━━━━━

最终作品应同时具有以下气质：

理性、实验、学术、文学、先锋、安静、冷峻、精密、神秘、知识密度高、具有独立出版物气息。

它应该像：

- 一张关于未知知识的专题杂志封面；
- 一份由设计师编辑的科学研究档案；
- 一个知识社群的年度视觉；
- 一张兼具学术性与艺术性的展览海报；
- 一页被放大成海报的实验性书籍版面。

作品需要让观者产生“值得靠近阅读和研究”的感觉，而不是一眼看完的商业广告。

━━━━━━━━━━━━━━━━━━
八、构图细节
━━━━━━━━━━━━━━━━━━

在画面中实现以下关系：

- 超大中文标题与科学插图发生遮挡和穿插；
- 英文标题放在顶部或中上部，与中文标题形成尺度反差；
- 荧光黄色区域承载部分主标题、图鉴或注释；
- 一幅主题主体图像跨越两个版面区域；
- 一到两个辅助图像被页面边缘裁切；
- 页面边缘存在非常小的出版信息；
- 细线从主体延伸到局部放大图；
- 至少出现一处圆形定位符或局部放大标记；
- 至少出现一组像学术索引一样排列的小型图像；
- 下方或侧边加入一段极小字号的专题简介；
- 保留足够负空间，不要填满整张画面。

构图看似自由，但所有元素必须受到隐形网格控制。

━━━━━━━━━━━━━━━━━━
九、原创性约束
━━━━━━━━━━━━━━━━━━

只借鉴“黑白科学图鉴、荧光黄色、实验性编辑排版、巨大中英文文字、知识档案拼贴”这一类视觉方法。

不要复制任何现有作品的具体：

- 标题内容；
- 插图对象；
- 图像位置；
- 黄色区域形状和位置；
- 页面编号；
- 标志；
- 字体组合；
- 文字排列；
- 构图比例；
- 裁切方式。

必须根据本次【创作主题】重新建立视觉隐喻、图像体系和版式结构。

最终作品应当像同一种设计文化中诞生的新作品，而不是对某一张参考图的复刻。

━━━━━━━━━━━━━━━━━━
十、禁止项
━━━━━━━━━━━━━━━━━━

禁止：

写实商业摄影、电影海报感、广告模特、3D 渲染、立体文字、玻璃材质、金属质感、霓虹灯、赛博朋克、柔和渐变、厚重阴影、镜头光晕、梦幻光效、卡通插画、可爱风、儿童绘本风、动漫风、极简 Logo 海报、企业宣传页、模板化信息图、居中对称构图、满版照片、过度复古、泛黄严重、颜色丰富、无意义装饰、杂乱涂鸦、低清晰度线稿、粗糙 AI 乱码、直接复制参考作品。

━━━━━━━━━━━━━━━━━━
十一、最终输出要求
━━━━━━━━━━━━━━━━━━

输出一张完成度极高的竖版实验性杂志封面或文化海报。

画面必须具备：

超大中文衬线标题、优雅英文斜体或衬线标题、黑白科学图鉴、主题相关结构图、荧光黄色平面色块、精细标注线、微型出版文字、非对称网格、局部裁切、大面积留白、旧档案印刷颗粒。

整体细节精密、层次丰富、版式成熟、印刷感真实，具有国际设计奖项参赛作品的完成度。

【创作主题】：xxx
```

### No. 3: 商品造型创意包装设计
