```
制作一张大胆的编辑风格活动海报，让超大字体像物理材料一样运作，而非保持平面与静态。

品牌：[BRAND NAME]

避免千篇一律的主体＋大字排版、随机变形、厚重 3D 字体、无意义填充文字、过多 UI 图形、杂乱，以及脱节的视觉效果。
```

```
[ANIME] 世界的超精细照片级写实等距微缩模型场景，呈现为一件悬浮于干净温暖米白色摄影棚背景之上的高阶收藏级景观雕塑，下方带有淡淡的自然阴影。

（为求最佳准确度，请上传官方地图／世界布局的清晰参考图。）

世界形状与地理

若 [ANIME] 具有虚构的世界、大陆、岛屿或地区，请精确重现其正史地图轮廓。整块陆地应看起来像是从大地实体切割并向上抬起的一整片连续微缩地形板，带有自然断裂的岩壁、外露的土层、悬崖与地质纹理。

若 [ANIME] 发生于真实或半真实地点，请以最重要的正史城市、地区或国家作为实体基础形状，保持其可辨识的地理轮廓。

外缘边界必须让人感觉像是直接从地图上切下的真实土地——绝不能像平面印刷地图或悬浮板。

正史世界重建

在整个微缩表面以最大限度的设定准确度重建 [ANIME] 的世界。

每个主要地区、聚落、城市、地标、山脉、河流、森林、道路、战场、城堡、神社、未来结构或其他可辨识地点都应出现在正确的相对位置。

保留动漫独特的视觉语言：

- 正史建筑
- 可辨识的环境
- 真实地形
- 派系领地
- 标志性地标
- 特征色彩
- 世界特有的科技或奇幻元素
- 环境氛围

避免通用的西方建筑或写实替换。成品必须立即让人感觉是 [ANIME] 化为实体微缩世界。

为重要地点加上细小但可读的位置标记，设计成优雅的博物馆风格制图标签，而非大字。

微观叙事细节

用精心布置的微缩叙事元素填满场景：穿着忠于作品服装的细小角色、世界特有的生物、载具、船、火车、旗帜、派系符号、市集区、农场、桥梁、小径、树木、植被及其他让世界鲜活的细节。

角色应维持为细小的环境元素，而非主导构图。

在整个地形中加入细微的活动，让场景如同动漫宇宙的活体快照。

材质与摄影

超写实的高阶微缩摄影结合高端电影感环境设计。

极其清晰的微观细节、写实的岩石构造、微缩植被、细小的建筑纹理、可信的比例关系与物理准确的材质。

一切都应保持清晰对焦，没有人工背景模糊。

使用来自上方的柔和温暖摄影棚照明，带有柔和的接触阴影及建筑、地形与岩层之间细微的环境光遮蔽。

微缩模型应具有精致的博物馆级收藏外观，同时保留动漫原有的视觉识别。

色彩与氛围

以 [ANIME] 真实的色彩语言作为主要视觉参考。

将动漫的标志性配色转译为写实的微缩材质，同时不失其可辨识的情绪、氛围或世界识别。

丰富但受控的色彩、电影感的色调深度、高阶印刷般的对比与写实的表面纹理。

构图

将完整成形的场景置中于 4:5 竖式画面的下三分之二。

在整块陆地周围留下宽裕干净的负空间。

场景绝不能触及画面边缘。

上三分之一几乎完全留白并保持米白色，营造精致的编辑海报构图。

在最顶端放置细小、宽字距的大写字体，显示世界／地区名称。

正下方放置：

[ANIME]

以粗体窄体无衬线字体，中等炭灰色，大而主导。

其下方加入一行较小、宽字距的大写文字，包含工作室名称与年份。

字体应如奢华的博物馆展览海报——克制、优雅，并次于微缩世界。

最终艺术指导

高阶编辑旅行海报美学 + 电影感微缩摄影 + 收藏级世界建构雕塑 + 博物馆级制图。

最终影像应看起来仿佛 [ANIME] 的整个世界被实体地从大地雕刻出来，并在专业摄影棚内拍摄。

不要通用奇幻地图、不要平面插画、不要随机地标、不要重复建筑、不要扭曲地理、不要过多文字、不要现代西方替换。

4:5 竖式比例、超高细节、照片级写实材质、电影感照明、高阶印刷品质。
```
