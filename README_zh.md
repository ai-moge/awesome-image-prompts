**艺术指导**

风格：[瑞士 / 粗野主义 / 包豪斯 / 极简 / 编辑风 / 未来感 / 建筑感 / 奢华]

打造精致的当代平面设计美学，而非通用的广告版面。每个元素都必须有明确的构图目的。

**01 — 视觉层级**

建立清晰的阅读顺序：

1. 主要：“[主标题]”
2. 次要：“[主体 / 图像 / 物体]”
3. 第三：“[副标 / 日期 / 细节 / CTA]”

主信息即使缩成小缩略图也要能被识别。

**02 — 字体排版**

把字体当作主动的视觉元素，而非单纯的文字摆放。

运用：

- 超大尺寸的展示字体
- 强烈的比例差异
- 紧凑而刻意的字距
- 受控的行距
- 策略性裁切
- 堆叠与垂直对齐
- 选择性的文字/主体重叠
- 适当处的字体遮罩

最多使用 1–2 种互补字体。

主要字体：[粗体窄体 / 无衬线 Grotesk / 衬线 / 自定义]
次要字体：干净中性的无衬线。

所有重要文字须拼写正确、可读且专业排版。

**03 — 构图**

用严谨的编辑网格搭建海报。

创造：

- 一个主导的焦点
- 强烈的对齐
- 清晰的边界
- 适当处的非对称平衡
- 受控的张力
- 刻意的负空间
- 一两个微妙打破网格的元素

避免把所有元素都放中央。让视觉重量在整个画面上平衡。

**04 — 主视觉**

以 [主体] 作为主要视觉。

呈现方式：“[满版 / 抠图 / 3D / 摄影 / 插画 / 剪纸 / 抽象]”

运用层次、遮罩、前景/背景关系或受控重叠，将主体与字体整合。

主体与标题应像是一个统一的构图，而非图片上叠放文字。

**05 — 比例**

运用戏剧性的尺度对比：

巨大：主标题或主视觉元素
中等：次要信息
小：辅助文案
极小：技术/编辑细节

避免所有元素使用相近尺寸。

**06 — 色彩**

色盘：

背景：“[颜色]”
主色：“[颜色]”
强调色：“[颜色]”

使用克制的 2–4 色系统，搭配一个主导强调色。

优先强烈的明度对比与可读性。
